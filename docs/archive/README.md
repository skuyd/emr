# 历史文档归档

返回[当前文档中心](../README.md)或[当前产品状态](../product/current-state.md)。

本目录用于追溯迭代决策、发布身份和原验证结果，不作为当前功能或进度依据。
归档整理基于源码版本 v5.1.0；原交付状态、提交和证据关系保留在[登记表](../document-registry.json)。

## 保留范围与读取规则

- 旧产品方案、阶段规格与计划：保留需求演变、验收编号和实现依据；现行合同见文档中心。
- 历史验证记录：保留执行范围、失败与限制，不将旧通过数视为当前全量通过。仍有效的缺口汇总在[验证入口](../verification/README.md)。
- 整理前快照：保留被整合文档的原始叙述，避免过程细节丢失；链接随受控迁移修复。
- 历史发布清单：因版本工具依赖继续存放在 `docs/releases/`，登记为 `archived`，由此处统一导航。
- 原 PRD 保留全部需求正文，仅修正上位方案的归档相对链接，并同步追踪源哈希；机器运行制品保留原路径、运行身份和哈希。

`superseded` 保留明确的取代关系，`archived` 表示退出当前工作；二者均只作历史阅读。
历史正文中的“当前”“未完成”“下一步”、环境描述及测试数字属于当时检查点，不覆盖当前说明。
