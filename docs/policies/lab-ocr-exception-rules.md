# 检验报告 OCR 异常处理规则

正式规则，适用于新报告和历史报告。更新日期：2026-10-01。实现进度见[实现与验证](#实现与验证)。

## 通用规则

| 项目 | 规则 |
| --- | --- |
| 原始数据 | 保留 OCR 原文、数值、字段位置和来源；人工修改通过修订记录保存 |
| 处理顺序 | 拆分字段 → 修正单位写法 → 按目录补全 → 必要时换算 → 判断展示与计算资格 |
| 标准单位 | 展示和计算以标准指标目录单位为准；目录为 `10^9/mL` 时保留该单位，不强制转换为 `10^9/L` |
| 数值 | 拼写修正不改数值；真实单位换算按倍率调整数值，保留比较符 |
| 适用范围 | 新报告解析、历史读取、核对页、检验指标和指标对比共用规则，无需逐条清洗历史数据 |
| 计算资格 | 单位修正只解决单位问题；指标身份、日期、来源和报告冲突分别校验 |
| 字段粘连 | 单位与参考范围粘连时先拆分；不能截掉无法解释的内容后直接计算 |

## 单位规则

### 计数单位

| 识别内容或条件 | 规范结果 | 数值处理 |
| --- | --- | --- |
| 指数为上标、带 `^` 或丢失指数样式 | `10⁹/L`、`109/L` → `10^9/L`；`1012/L` → `10^12/L`；`106/L` → `10^6/L`，其他指数同理 | 不变；只处理单位字段 |
| 指数单位开头有 `×`、`X`、`x` | 省略乘号；`×10^9/L`、`X109/L`、`x109/L` → `10^9/L` | 不变 |
| 升的大小写不同 | `l`、`L` → `L` | 不变 |
| 毫升写成 `ML`、`ml`、`mL` | 统一为 `mL`；`109/ML` → `10^9/mL`；`1012/ml` → `10^12/mL` | 不变，保留毫升含义 |
| 缺少分母，目录能确定 | 仅补分母，保留原指数；`109` + 目录 `10^9/mL` → `10^9/mL`；`106` + 目录 `/μL` → `10^6/μL`，再按需要换算 | 补全时不变 |
| 缺少分母，目录无法确定 | `109` → `10^9`，分母留待核对，不默认补 `/L` | 不进行单位换算 |
| 无表头或指标未匹配目录 | 同样识别并规范单位；结果、单位和参考范围分别归入对应字段 | 不授予未知指标计算资格 |
| 全角、空格混入单位 | 先识别完整单位；`X 109 / ML` → `10^9/mL`，不丢弃分母后补 `/L` | 不变 |

### 微量前缀与摩尔单位

| 识别内容或条件 | 规范结果 | 数值处理 |
| --- | --- | --- |
| 表示微量前缀的 `u`、`µ` | 统一为 `μ`；`ug/L` → `μg/L`，`uL` → `μL` | 不变 |
| `umol/L`、`μmol/L`、`µmol/L` | `μmol/L` | 不变 |
| `umo1/L`、`μmo1/L`、`µmo1/L`、`Umo1/L` | `μmol/L` | 不变；恢复前缀或字母 l |
| `mmol/L`、`mmo1/L`、`Mmo1/L` | `mmol/L`，独立的毫摩尔单位；统一大小写并恢复字母 l | 不变；不按 `μmol/L` 的拼写处理 |
| `U/L` 等其他单位 | 保留原意，不将任意 `M`、`m`、`U` 替换为 `μ` | 不变 |

### 无单位与百分比

| 识别内容或条件 | 处理规则与示例 |
| --- | --- |
| 目录明确无单位 | 保持空单位，不提示“缺少单位”；如白球比值、尿比重 |
| 原文为 `%`、`％` | 保留百分比含义；目录支持时统一显示 `%` |
| 目录为 `%`，识别单位为空或只有空格 | 补 `%`，数值不变；大型血小板比率 `23.5` → `23.5%`，`0.4` → `0.4%`，不再因空单位阻断计算或提示缺少单位 |
| 目录为 `%`，原单位明确为 `L/L` | 按实际倍率转换；`0.4 L/L` → `40%` |
| 单位为空且未匹配目录 | 留待核对；不能仅凭名称或字典 `unit_forms` 为空认定无单位、补百分号 |

### 实际单位换算

| 原值 | 标准指标单位 | 处理结果 |
| --- | --- | --- |
| `5.2 10^9/mL` | `10^9/mL` | 保持 `5.2 10^9/mL`，不换算 |
| `5.2 ×109/ML` | `10^9/mL` | `5.2 10^9/mL`，只修正写法 |
| `5.2 10^9/mL` | `10^9/L` | `5200 10^9/L` |
| `5.2 10^9/mL` | `10^12/L` | `5.2 10^12/L`，指数与体积共同决定倍率 |
| `5.2 10^9/L` | `10^12/L` | `0.0052 10^12/L` |
| 真实的 `1 mmol/L` | `μmol/L` | `1000 μmol/L`，倍率依据：[SI 前缀](https://www.bipm.org/en/measurement-units/si-prefixes) |
| `13.2 g/dL` | `g/L` | `132 g/L` |
| 量纲不兼容或没有换算依据 | — | 保留单位问题；不能把计数单位直接当作 `g/L` 或 `%` |

## 指标名称与数值

| 情形 | 处理规则 |
| --- | --- |
| 已审核别名、缩写 | 匹配标准目录，保留印刷原名 |
| 中文名、缩写或同名项目冲突 | 用标本、报告类别等上下文消歧；无法唯一匹配时保留候选，不强行合并 |
| 人工选择标准指标 | 使用有修订依据的标准编码；无需改写 OCR 原名 |
| 项目序号、代号有疑点 | `row_number`、`project_code`、`row_code` 只影响名称和标准指标身份，不扩散为日期问题 |
| 疑点明确影响日期，或影响范围不明 | 保留日期相关限制 |
| 普通数值 | 使用有界 Decimal 运算 |
| `<5`、`≤5` 等比较符结果 | 保留比较符；满足条件时可对照参考范围，不作为精确数值参与趋势或变化计算 |
| 阴性、阳性、未检出等 | 保留原类型，不转成 0 或虚构数值 |
| `1,23`、`O.5` 等数字疑点 | 生成修正候选，核对后生效 |
| 内容与结果类型不一致 | 标记 `type_conflict`，限制计算 |
| 非有限值、过长数字、极端指数 | 保留原文；超出表示范围标记 `numeric_unsupported`，有效数字最多 128 位 |
| OCR 置信度或关联证据不足 | 基础抽取门槛 `0.80`、标准名称门槛 `0.90`、未确认来源的趋势等检查门槛 `0.95`；旧抽取路径不发布低于基础门槛的行，第二阶段可保留候选 |
| 历史量级、报告内部一致性 | 仅在有完整、已审核规则时检查，不对所有指标套用推测规则 |

## 日期与确认

| 情形 | 处理规则 |
| --- | --- |
| 日期来源 | 使用采样、采集或采血时间；要求完整日期和时分，不用打印或报告时间自动替代 |
| 日期缺失、证据不足、相互冲突 | 分别保留缺失、不确定或冲突状态 |
| 历史整单已确认但 OCR 日期置信度低 | 当前身份为 `ACCEPTED`、有采样时间，且该报告最新整单确认快照与当前身份一致时，复用确认依据 |
| 借用续页或关联来源的时间 | 当前提供时间的报告单元必须仍在确认记录来源中；来源关系改变或提供时间的报告重新解析后，不直接沿用旧确认 |
| 日期缺失、身份为 `REVIEW` 或存在真实冲突 | 不用历史确认绕过；不改写原置信度或伪造确认记录 |
| 只确认单个结果或仅保存修改 | 不视为确认整份报告的采样证据 |
| 有效人工确认 | 可解除已确认字段的识别或关联疑点；仍须排除识别有误标记、修订冲突和报告冲突 |
| 新解析与已确认内容冲突 | 重新核对；旧确认不能补出缺失单位、标准指标或可用来源 |

## 展示与计算

| 项目 | 规则 |
| --- | --- |
| 计算范围 | 单位换算、参考范围对照、趋势绘图、相对上次或个人基线的变化；不重新生成检验结果 |
| 变化指标 | 可计算差值、间隔天数、变化百分比及近三次平均值；基准为零或负数时不算百分比，同日无法确定先后时不任取基准 |
| 参考范围 | 优先使用适用的目录范围，按性别、采样时年龄、生理阶段选择；无法唯一确定时不补默认范围 |
| 无目录的结果 | 可依据原报告范围和标记解释；标记无法识别或与范围冲突时显示异常状态无法计算，不推导诊断 |
| 提示生成 | 使用规范化并按目录补齐的单位；已确认结果显示计算限制，未确认结果显示待核对原因 |
| 标本、检测方法 | 核对、指标和对比页面不展示，也不提示缺少标本或方法；底层身份消歧、可比性校验保留 |

| 页面提示 | 触发条件 |
| --- | --- |
| 缺少单位 | 数值或比较符结果仍缺有效单位，且不属于目录无单位项或可补 `%` 的项目 |
| 单位无法换算 | 修正、补全后仍不完整或无法换成所需单位 |
| 缺少日期 | 没有可用日期 |
| 日期依据不足 | 日期、来源或相关字段证据不足 |
| 日期存在冲突 | 日期依据相互矛盾 |
| 缺少标准指标 | 未完成标准映射或仍为候选编码；单位已识别也可能出现 |
| 结果类型不支持计算 | 内容与登记类型不一致 |
| 结果无法计算 | 数值超出程序表示范围 |
| 来源不可用 | 原始证据或所属资料不可用 |
| 缺少可用参考范围 | 原报告和目录均无可用范围 |
| 参考范围无法计算 | 原范围存在冲突，且无可用目录范围替代 |

## OCR 任务失败

| 情形 | 处理规则 |
| --- | --- |
| 可重试错误 | 最多延迟重试 3 次，间隔 60、300、1800 秒；耗尽后失败 |
| 不可重试错误或契约错误 | 记录稳定错误码并失败，不自动重试同类错误 |
| 未分类异常 | 使用 `unexpected_processing_error` 进入重试，不保存原始异常正文 |
| 无结构化结果 | 保留原件，按 `ORIGINAL_ONLY` 状态发布 |
| 旧任务失去执行资格 | 停止发布，避免覆盖更新结果 |
