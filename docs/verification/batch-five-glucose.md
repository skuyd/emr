B5-02 已实现独立血糖记录、原件核对导入、日内曲线、多天时段表，以及选定速查、导出和
限时分享。本地相关回归、实际 PostgreSQL 与 Chromium 验证通过；来源、页面和输出的

| 选定输出 | 只选血糖且无上传资料时也可生成 PDF、JSON/CSV/ZIP；混合检验、影像字段、日常记录及治疗派生内容分别保留选择范围 | `test_export_integration.py`、`test_output.py`、`tests/exports/test_treatment_exports.py` |
| 限定分享与撤回 | 分享只投影选定当前记录；不包含作者账号、完整历史或未选原文；更正、作者注销或撤权后旧预览、发布、分享及后续下载块均拒绝 | `test_output_lifecycle.py`、`tests/integration/test_glucose_export_postgres.py`、实际浏览器用例 |
| 迁移与清理 | 新记录及来源绑定不伪造上传文档；迁移保留既有日常记录、临床数据和旧导出/分享；作者注销保留其他家庭患者记录并置空作者 | `test_migrations.py`、`test_lifecycle.py`、既有家庭/分享迁移用例 |

时段必须有原件明确依据或用户选择，不按时钟或 `LAB_FASTING_GLUCOSE` 编码自动断言空腹。
原报告的日期、月份或时间未知状态不补成午夜。夏令时不存在的时刻拒绝；重复时刻要求
明确分支。只改数值时保留原秒值，改日期或时区时重新解析。

mg/dL 换算使用规格记录的 `value × 0.05551`，十进制计算、界面舍入和原值分开保存。
比较符、范围、HI/LO 或无法确认单位的内容保留原文及原因，不取中点或制造曲线值。
颜色表示显示数据中的相对数值，不设置疾病判断或治疗阈值。

## 选定范围与当前性

结构化格式从实际已合主线的 `1.3` 扩为 `1.4`，新增 `glucose_records` 与
`glucose_record_sources`，保留临床、日常记录和八张治疗相关表。读取器接受 `1.0` 至
`1.4`；旧文件缺失的新表按空数组读取，`1.4` 必须提供两张血糖表。

原件导入血糖的文档作为私有失效依赖参与锁定和指纹校验，不因此出现在选定资料表，
也不因此给分享接收者整文档权限。完整原件需要另行明确选择。只选血糖的限定分享
拒绝普通记录历史和原件路由；范围检查覆盖真实 JSON、CSV、ZIP 清单、PDF 文字及 HTML。

实际大文件测试生成 130 条合成记录的 JSON。收到第一块 256 KiB 后更正选定记录，
后续生产流停止；重复关闭流只记一次拒绝审计。混合日常记录/血糖作者注销的 PostgreSQL
检查在真实删除收集器更新部分数据、事务尚未提交时暂停，确认读取等待实际 COMMIT，
之后清空并拒绝失效快照。
