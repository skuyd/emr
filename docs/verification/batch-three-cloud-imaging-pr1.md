## 当前实现与来源边界

| 能力 | 当前结果与可核对入口 |
| --- | --- |
| 本地扫描 | 资料详情可发起扫描；本地 worker 处理原页和固定 OCR 明文，保存扫描状态与失败；GET 不触发扫描 |
| 原页证据 | OCR 保存真实原词、Unicode 区间和页几何；QR 保存实际渲染/尝试图像、变换及原页区域，不伪造 OCR 偏移；人工补录标明转录来源 |
| 核对与归属 | 资料/报告页进入来源列表，查看原页，确认、更正、排除、归属及撤销；同页多报告保留歧义，决定保存实际作者和追加修订 |
| 角色与生命周期 | READ 查看核对结果；扫描和决定需 WRITE。服务、worker 和最终 HTML 校验患者、原件、报告、修订与作者状态；旧令牌或并发冲突要求重新核对 |
| 默认输出保护 | 普通预览、PDF、JSON、CSV、ZIP 与分享不自动带入外部访问串；省略上下文有标记且清空 offset，固定转换依据 URL 仅接受服务端确认的精确规则例外 |
| 旧输出消费 | 构建、发布、预览渲染和下载各阶段检查旧快照；含未许可访问串的旧输出失效，不能借旧格式或原件 ZIP 元数据绕过 |

默认省略只发生在输出投影，不改写原始 Fact、OCR、私有来源证据或已确认字段。用户另行
明确选择整份原件时，原页可能包含 URL/二维码，仍按原件权限交付；本系统不能从已下载
原件中撤回这些信息。当前没有对外打开路由，也没有云来源的显式导出/分享控件。

主要实现位于 [cloud_imaging](../../apps/cloud_imaging/)、
[输出投影](../../apps/cloud_imaging/projection.py)、[旧输出检查](../../apps/exports/content.py)、
[分享投影](../../apps/patients/sharing_content.py)与[本地 worker](../../apps/processing/management/commands/run_local_processing_worker.py)。

## 首次真实固定源执行

先冻结 64 份原件及对应的 64 份固定 OCR，保留全部 124 页，再冻结标注和评分协议。
每份文件使用独立的合成患者容器，不由共同文件名或页面内容猜测跨文件患者关系。
124 页均有总览，但只有 16 页完成可用于存在性判断的完整原图核对；其余 108 页保持
未判定，不能把总览未见二维码视为阴性。

先人工标定 6 个标准方形二维码区域，再用独立的 ZXing-C++ 3.1.1 对预定区域解码。
按冻结协议，至少两次有效原始字节相同才判定载荷；其中 4 个可判断、2 个未知。
应用预测使用 OpenCV 4.10.0.84，与金标解码器分离。3 个圆形小程序码另列能力范围，
不计为已支持的标准 QR。明文金标来自原 PDF 字符和完整原页核对，不来自固定 OCR 或
应用候选；跨行无法唯一恢复的载荷保持未知。

根代理按唯一批准执行一次实际本地扫描：64 个扫描均完成，零执行错误，124 页和
1108 份实际解码尝试图像有可核对身份；数据库发布 73 条候选，全部为 QR。
73 是候选数，不是已确认的云影像入口数。运行导入固定 OCR 作为来源，没有重新运行
OCR 或临床字段提取，也没有访问任何真实 URL。全部逐源预测及空结果保留后才评分；
根代理又只读核对数据库、制品和输入身份，没有重预测或重评分。
