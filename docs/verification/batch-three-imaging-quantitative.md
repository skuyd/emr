# 第 3 批 SUV 与对比原文字段验证

本项对应[五批需求](../specs/2026-09-07-batches-one-five-requirements.md) B3-01/B3-02，
细化契约见[剩余规格](../specs/2026-09-08-clinical-followup.md)。在已合入的七类字段基础上，
新增原文 SUVmax、明确最大/较大限定、对比原文及引用日期，贯通原件核对、修订、搜索、
速查、CSV/JSON/ZIP 和选定字段分享。当前正在验证及准备独立审查，尚未合入 main，
版本未确定。B3 及五批整体仍为 `implementing`。

固定开发集的四类新字段共 **54 个明确目标**。首轮严格正确 27，来源边界修复后为
33；仍有 **10 条错配、11 条漏提、2 条额外候选**。45 条候选都需要原件核对，其中
12 条需要更正、核实来源或移除，另有 11 个明确字段需要补录。不能将新字段的小样本
结果解释为整个 B3 或自动医学提取已达到准确率目标。

## 实际实现与保留边界

| 范围 | 行为 |
| --- | --- |
| SUVmax | 保存十进制原值、比较符/范围、约数、明示单位或空、本次/历史/不详；不取 SUVmean、显像剂剂量、摄取时间或背景组织参考值 |
| 较大限定 | 只保存原文明示的组内较大者或全报告最大病灶；不从不完整候选求最大值 |
| 对比 | 保存完整对比原文和明确引用日期/精度；报告内 `comparison:*` 不代表已关联另一份检查 |
| 来源 | 保留实际 OCR 块、原始 Unicode 区间和原件页/坐标；规范化不覆盖原串，字段不借另一条字段证明来源 |
| 旧数据兼容 | 原七类字段模式维持 `1.0`，新增字段为 `1.1`；部署新增模式不抹去原有确认 |
| 核对修订 | 确认、更正、暂缓、排除、明确页补录、撤销确认及撤销上次操作；实际作者和不可变自动内容均保留 |
| 携带与分享 | 复用 JSON 1.1 报告/字段/来源数组及对应 CSV；选定字段只携带有效值和安全来源身份，不带出其他测量、原文上下文、报告跨度或整件权限 |
| 失效与权限 | 字段撤销、父报告排除/替换、重解析、删除恢复、撤权均继续受主线来源令牌、患者锁及快照指纹控制 |

CODED 核对表单区分类别原词和完整来源，避免未改动的原文侧别/最大限定被确认成整段
文字。SUV 更正后的显示从有效数值和限定生成；原始 OCR 数字仍可在核对页面的来源和
自动候选中查看。所有新自动字段仍是待核对候选，未确认的字段不进入默认就诊资料。

跨报告稳定病灶关联、趋势、已有检查关系、云影像、病理/分子及癌种排序继续按
[六项实施计划](../plans/2026-09-08-clinical-followup-implementation.md)交付，不能把本项
的四类字段当作剩余 B3 已完成。

## 固定规则与完整分母

新评分器 `clinical-imaging-followup-source-v1` 与原七字段评分器分别保留身份。新任务仅
评分预先声明的四个键，完整流水线输出保留所有新旧字段、失败文件、报告和未分段页。
原七字段显式投影使用原 gold 和未修改的 `clinical-field-source-v2` 评分器。

报告内实体根据原文相似度和部位锚点一对一分配，不按预测值是否正确挑选配对。逐字段
校核冻结定位或原文：对比须证明完整原句，SUV/最大限定须在其对应原文内包含自己的
部位与数值/限定表达。同页可读、孤立数值或另一个器官的同值不能算正确。无法证明的
