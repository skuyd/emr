## 已实现行为与验证入口

| 用户行为 | 实际结果与边界 | 主要验证入口 |
| --- | --- | --- |
| 快速新增记录 | 体重、体温、症状分开录入；原始数字、单位、时间、时区与偏移保留；同一分钟的两次测量保留独立身份 | `tests/self_records/test_payloads.py`、`test_services.py`、`test_views.py` |
| 核对和更正 | 首次输入不可覆盖，更正、删除、撤销追加作者与前后值；同一修订并发写入只有一项成功；幂等重试不重复创建 | `tests/self_records/test_services.py`、`test_audit.py` |
| 查看历史 | 列表每页最多 50 条；本页图表按实际时刻绘制，体重与体温独立数轴，同刻值分别保留文字来源；可筛选时区、日期、类型及翻页 | `tests/self_records/test_history.py`、`test_accessibility.py` |
| 家庭协作 | 只读成员可查看，协作者可写入；旧标签页仍指向原患者；响应发出前复核当前成员资格 | `tests/self_records/test_views.py`、`tests/integration/test_self_records_postgres.py` |
| 记录单独导出 | 无上传文档时可生成记录速查 PDF、JSON/CSV/ZIP；不创建虚假文档，未选记录不进入包，空包被拒绝 | `tests/self_records/test_exporting.py`、`test_export_integration.py` |
| 混合选定资料 | 影像字段与日常记录分别选择；即使患者存在影像资料，记录单独导出或分享也不自动包含影像字段 | `tests/self_records/test_clinical_integration.py` |
| 限时分享与来源变化 | 接收者只看到选定记录的当前值；不含作者账号标识、原始修订或普通历史链接；记录或临床字段修订后旧快照失效 | `tests/self_records/test_lifecycle.py`、`test_clinical_integration.py`、`tests/browser/test_self_records_browser.py` |
| 迁移与清理 | 新来源绑定迁移保留既有记录、修订及旧导出/分享内容；作者注销保留其他家庭患者记录，患者删除按生命周期清理 | `tests/self_records/test_migrations.py`、`test_lifecycle.py`、`test_audit.py` |

数值采用十进制解析，kg/g/lb 与 °C/°F 的原值和换算公式同时保存。不会按人体参考范围
截断数值、推断疾病或自动判定症状程度。夏令时不存在的时间、缺少明确偏移的重复时间
返回输入错误；不完整时间不会补成午夜。表示能力的长度和指数边界独立于医学范围。

结构化导出数据格式为 `1.2`：新增 `self_records`，保留已交付的报告、字段和来源表与旧表列。
读取器接受 `1.0`、`1.1`、`1.2`；旧文件缺失的新表在读取结果中为空，不改写文件字节。
该格式号与 Release Please 管理的应用版本分别维护。

## 开发失败记录与交付余项

独审使用真实 GET 表单值和手机 Chromium 发现旧 `utc_offset` 被预填在折叠区域：原记录
处于夏令时时，只改为冬季日期或其他时区会被错误拒绝；改为新的重复分钟还会沿用旧偏移
自动选择一次。永久 HTTP 用例在修复前为 6 失败、11 通过，实际手机回归为 1 失败。

修复提交 `8b81ce288113412de95bd94dd37bb667f5d92a33` 只改一个应用文件
`apps/self_records/forms.py`，并补充 HTTP 与浏览器用例。编辑时不预填偏移；原日期、分钟
和时区未变、用户又未指定偏移时复用当前记录原始时间字符串，因此仅改值仍保留原分支。
日期、分钟或时区改变则重新严格解析，新重复时刻要求明确选择，春季不存在的时间仍拒绝。

该提交的日常记录、导出及临床分享相邻范围 **160 项通过**（69.06 秒），必跑实际浏览器
**4 项通过、0 跳过**（32.44 秒），含手机跨季更正、新歧义提示、显式选择和随后仅改值保留
分支的完整流程。根代理已查看新的手机选择截图。完整套件和 PostgreSQL 的上表结果仍
对应初始 `63540c08`；修复后的全量结论等待最终 PR CI。

独立复审确认唯一 P2 已关闭，最终无未解决 P1/P2。审查者读取真实差异，核验 62 份源码与
