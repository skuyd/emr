# 第 3 批结构化证据基础与首批影像字段验证

本记录对应[五批完整需求](../specs/2026-09-07-batches-one-five-requirements.md) B3-01、
B3-02 和[基础规格](../specs/2026-09-08-clinical-evidence-foundation.md)。首批七类字段已
贯通 OCR 分段、持久化、原件核对、修订、详情、搜索、速查和 CSV/JSON/ZIP。
固定开发集的严格正确字段由 **24 增至 37**，漏提 **44 降至 18**；最终仍有
**50 条严格错配和 10 条额外候选**，其中 47 条来源证明未核实。所有 97 条候选均需
对照原件，不能据此宣称达到自动医学提取准确率目标。

本次基础范围经本地验证、基础与家庭集成两轮独审、功能及发布 CI 通过，已随
[v1.9.0](../releases/v1.9.0.md) 发布，登记为 `verified`。B3 整体及五批总状态仍为 `implementing`。
本次不代表整个 B3 完成：SUV、跨报告稳定病灶关联、病灶趋势、对比检查关联、云影像、
病理及分子/基因字段仍由后续 PR 实现。公开制品只含计数、方法和哈希；原件、OCR、
原始标注及带原文的预测保留在授权本地位置。

## 已实现的核对链路

| 范围 | 实际行为与验证 |
| --- | --- |
| 报告边界 | 明确标题、同页并列报告、拆分表头、相邻明确续页；混合资料中无独立报告锚点的页保留为未分段 |
| 首批字段 | 检查日期/精度、方法、检查部位、局灶异常位置、明示侧别、有序尺寸与原单位/轴/约数/时间角色、完整结论 |
| 原始证据 | 逐字段保存 OCR 块、原始 Unicode 半开区间、原件页和几何；匹配规范化不覆盖原串或坐标 |
| 核对 | 确认、更正、暂缓、排除、补录、撤回确认、撤销上次操作；保留自动内容、变换原因和实际作者 |
| 父子修订 | 整体排除/撤销为每条字段追加审计；人工替换范围建立新报告，字段重新核对；后续字段操作阻止父操作覆盖 |
| 来源失效 | 重解析、切回旧版本、删除恢复、无 OCR 人工报告首次解析均不能复活旧确认；旧导出失效 |
| 读取与权限 | 当前字段进入详情、搜索和速查，同字段冲突值分别展示；实际成员身份、只读权限、跨患者、撤权和生成后的复查 |
| 精细分享与审计 | 实际表单选择报告/字段及显示章节，隔离同件其他报告、旧摘录及未选字段；报告访问按真实患者和操作者记录审计 |
| 携带格式 | JSON 1.1 新增报告/字段/来源三个数组，CSV 新增同名表，旧摘录 CSV 列不变；ZIP 保留关系及所选原件字节 |

人工无 OCR 报告必须明确选页和作者。报告内 `entity_key` 只代表本报告的实体，不能
当成患者长期病灶 ID。更正不会抹去原候选；报告来源、逐字段来源和修订均参与快照
指纹。导出生成期间发生字段或父报告变化时，发布前再次检查并拒绝旧制品。

报告/字段细选只带出另外明确选择的旧摘录和检验。字段细选保留类型化有效值、显示
文字、身份、页与原件坐标，省略整句原文、上下文字符区间和整报告 spans，并明确说明
上下文省略。完整报告导出仍可携带该报告的核对上下文。若用户另外勾选完整原件，
界面提示其包含整份文件；不把字段选择解释为自动裁剪 PDF。分享仍须按其独立资格、
报告/字段和显示章节投影，不将一字段选择扩大成整个原件授权。

已集成已合并的家庭邀请、分享与访问审计：精细分享拒绝完整原件来源和下载，不携带
字段 `raw_value`、变换片段或整报告上下文；只读页面自动转义展示有效值。字段撤销、
父报告排除、解析启用或新增报告范围后，现有访问资格返回 410 并清除旧快照。报告
读取、排除、提取及补录均按实际报告/原件所属患者记录真实操作者；访问者自己的当前
患者不会覆盖资源归属，审计不记录医疗正文。

## 来源退化、修复和人工核对量

严格规则发现初始 24 条正确中的 3 条在审查前退化。原件独立核查确认：照片左侧邻页
窄条的 3 个字符被前置到正面报告的完整来源句，影响同实体的部位、侧别和尺寸；
三值未变，但来源确实污染。修复仅限定临床报告分段，不修改旧摘录的通用布局。

现在以同页明确所见与结论标签识别正文左界；落在界外、触及图像边缘且没有报告锚点
的窄列记为未归属，原 OCR 和完整原件仍可查看。正常宽正文、非贴边片段、缺少双锚点
或有独立报告标题时不套用该规则。报告记为范围受限，字段和报告页提示查看整页，
必要时人工调整范围。合成回归先复现污染，再验证原件/布局坐标、入库、原文保留和
可见提示。修后初始 **24 条严格正确、46 条值匹配均逐条全部保留，退化为零**。

去除邻页窄条后，正面报告跨行恢复的一个否定淋巴结描述新增了额外部位候选。
它的来源在正确物理报告中，但否定标记和关键词相隔七字，超出现有紧邻否定匹配。
独立复核确认该归因；它仍计为额外，没有重开标注或隐藏在未判断范围。
独立实际流水线及 HTTP 探针确认该条为 `FIELD / PENDING / revision 0 / usable=false`，
完整否定原文保留在 `raw_value` 和不可变来源片段，详情页可见；没有同实体尺寸。
它不是已确认病灶，默认速查及结构化导出不纳入，显式选取该未核对字段也被拒绝。
当前字段没有独立的 `NEGATIVE` 枚举，核对者须依据保留的完整否定原文决定处理。
逐条保留与该限制见[保真制品](artifacts/batch-three-clinical-retention.json)。
