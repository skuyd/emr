# 功能删减与检验对比精简验证

## 已确认范围

2026-10-01 用户要求删除治疗周期、多指标对照、核对就诊事实、健康趋势，并追加删除血糖记录。

- “核对就诊事实”删除独立汇总页面、路由及入口；保留影像、病理、分子报告和就诊导出仍使用的单份报告核对与共用数据。
- 治疗周期和血糖记录删除专用工作流及导出、分享入口。用户明确选择增加迁移，删除两项功能的专用表和历史数据。
- 保留原始医疗资料、事实中的治疗原文，以及检验报告中的血糖指标。其他日常记录与病灶功能不属于本次删除范围。
- 健康趋势与多指标对照删除页面、路由、导航、专用脚本、样式和无剩余调用的计算逻辑。普通就诊导出仍使用的检验数据处理保留。
- 检验对比保留日期和指标查询、分类选择、结果表格与表格内的来源核对；删除顶部说明和辅助导航、趋势开关、趋势列及重复的单位列。单位仍随指标或具体结果显示。
