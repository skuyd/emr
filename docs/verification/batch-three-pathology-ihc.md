按实际锚身份分组，不用相同省略文本合并两个标本。隐藏来源变化仍使旧输出失效。

临床报告锚，56 份来源有对应未覆盖理由。重放总流程的 45 success 和 19 original_only

合成患者容器，不推断跨原件患者关系。数据库没有归档；独立回读只检查原始映射回执与
严格执行守卫，未声称重新打开已消失的数据库。自动候选 revision 0 不代表用户确认。

独立回读核对 1227 个 tracked 文件、391 个运行源码、6 个工具、3477 份旧保护文件以及
128 原件/OCR，联合 4734 文件和两种 index 身份前后不变。没有导入或执行应用、mapper、
scorer，也没有用文件时间冒充预测写入先于评分的系统调用证据。
