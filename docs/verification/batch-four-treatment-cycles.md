## 实现行为

| 范围 | 已实现与验证的行为 |
| --- | --- |
| 治疗证据 | 独立保存原文自动事件和本人补记；发生状态、日期精度、方案原词、明确 C/D、来源与原始片段分别保留 |
| 自动提议 | GET 只读计算；依据有效治疗摘录、明确绑定的住院日期及本人记录形成待核对方案/周期；POST 锁内核对完整输入并固化原稿 |
| 限制 | 计划、医嘱、否定、未知日期与冲突不混成已执行治疗；不从检验最低值创造给药日，不给未知末周期填结束日期 |
| 决定 | 确认、更正、拒绝、撤销、合并、拆分、检查归属更正；原稿、每次前后值、真实作者、幂等操作与关联历史保留 |
| 档案组织 | 日历与周期视图保留原档案搜索、年月、类型、状态、分页和原件集合；显示区间不宣称治疗持续时间 |
| 相对天 | ANC/PLT/HGB 按原可比组显示实际日差，保留负日、同日多条和不可绘制原因；关键节点与完整模式共用原始数据 |
| 选定资料 | HTML/PDF/JSON/CSV/ZIP 与限时分享使用同一选定快照；本人补记可作为无文档独立来源，不伪造 Document |
| 失效 | 完整输入、来源修订、解析/资料生命周期、新边界、成员资格与决定状态共同约束预览、worker 发布、下载与分享 |
| 读取一致性 | 详情及表单选项返回前复验实际材料、源状态和历史作者；渲染期间变化则返回不含旧载荷的 409 刷新提示 |
