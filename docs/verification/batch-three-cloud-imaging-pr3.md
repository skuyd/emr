## 选择与输出

| 维度 | 实际边界 |
| --- | --- |
| 云来源选择 | `selection.cloud_source_ids` 默认空，普通资料、影像章节或报告选择不隐含来源许可；表单提交同时绑定显示时的来源令牌 |
| 来源独选 | 文档集合可以为空。私有依赖仍包含原件、页、证据、报告状态、当前及历史作者、来源修订和规则身份 |
| 混合选择 | A 原件和 B 来源可以共存，实际 ZIP 仅包含 A 原件字节。B 的来源标识不授予 B 原件访问 |
| 报告与字段范围 | 来源必须属于明确报告范围与字段报告范围的交集。空范围、未归属来源及任一无效 ID 整体拒绝，不静默丢弃 |
| 可移植关联 | 独立 `cloud_imaging_sources` 和 `cloud_imaging_evidence` 表保留来源／修订、原件／页／报告身份；二维码无 OCR 偏移，原始载荷、历史地址及整页文字不导出 |
| 地址保护 | 仅选定来源行的 `current_url` 保留原始语义；其余 URL 继续省略。CSV 公式防御、PDF/HTML 转义及离线表结构／关系验证覆盖新内容 |

选项旁说明下载文件可能包含访问参数。来源独选不生成虚构 Document，不把私有清理索引
当成公共文档集合。旧格式缺少新表时缺省为空，所有实际已发布领域数组与验证必须保留。

选择表单显示脱敏的原件名、标题、页码、来源类型和按建立顺序排列的页内来源序号；
短来源标识发生前缀碰撞时延长。每项另有内部来源核对入口，可继续查看准确原页。
同站点、同页码、同修订及同名的来源仍可区分，完整地址和访问参数不进入默认选择表单。
相似来源测试同时覆盖不同原件和同一原件同一页，并验证只导出／只分享实际勾选的一项。

## 精确分享与失效

分享快照仅显示安全站点、来源类型、修订及必要页／报告身份，不含原地址、二维码载荷、
作者账号或历史。接收者必须通过实际分享令牌交换，并绑定自己的账号、登录会话及期限；
创建者身份、成员修订和资格同样持续核验。

分享 GET 说明页和 POST 打开路由位于 `/shared/<share_id>/cloud-imaging/<source_id>/`。
目标仅从当前真来源绑定解析，不调用家庭 READ 代替分享授权。原件另按明确文档许可检查，
仅有来源分享的接收者不能访问完整原件、普通私有来源或其他未选来源。

来源、证据和文档使用真 FK 与冻结身份。分享 scope、快照选择与实际绑定必须完全一致；
删除、增加或丢失一项均使旧分享整体失效并清空快照。排队、worker 构建、存储发布、
预览渲染、跳转响应、下载 IO、首字节和每个读取块前后均保留重新核验。存储锁期间的
正常来源写入须等待锁释放；提交后下一次输出必须被阻止。

来源独选导出在私有文档清理索引中登记，来源独选分享不加入 `ShareSource`。实际非空
导出对象随原件硬删除被发现和清理；存储失败保留重试状态，重试成功后才删除原件聚合。
回收站恢复、撤销决定或重新登录不会恢复已失效输出。

## 已观察的测试与修订

下列是实施期间的有界事实，运行范围重叠，不相加，也不替代最终冻结头验证。

- 相关完整回归曾为 553 通过、5 个 PG 项目排除；该运行后继续追加范围和异常保护修订。
- 专用 PostgreSQL 27 项通过，另有 2 项真实跨领域部分作者清理提交及 1 项来源 FK 单独
  更新等待用例通过。均使用独立合成测试库，最终全套尚待重新冻结。
- 实际 PDF 文本、JSON/CSV 表、ZIP 清单和原件字节已验证；同页 OCR/QR 来源、报告／字段
  范围、Unicode／编码路径／重复查询参数及 CSV 公式文本有永久回归。
- 中途审查指出分享 scope 云来源集合未与快照比较，已补整体失效检查和新增／移除 ID
  的真实 HTTP 反例，修订后相关 45 项定向测试通过；仍需最终独立复审。
- 作者异常报告测试最初 2 失败、1 通过，确认 `/visit/` 的异常链可能带出合法选中地址。

  沿用早期保护。修订后 35 项定向测试通过。

  `no-referrer`，原生表单因此提交 `Origin: null` 并被真实 CSRF 拒绝。作者修订 `084e29a`
  恢复导出的 `same-origin`；外部受控打开继续 `no-referrer`，未放宽 CSRF。实际两尺寸
  TLS 和三项异常报告复测共 5 项通过、零跳过。

  新作者修订将分享 GET／POST 纳入早期异常报告保护，保持原生 CSRF；增加上述选择线索
