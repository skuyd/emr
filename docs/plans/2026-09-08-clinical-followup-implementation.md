## 单个交付的步骤

1. 明确字段、实体、关系和来源失效契约，先冻结独立真实标注范围；不足部分声明未评测。
2. 先记录有意义的合成行为失败，再实现真实 OCR 到数据库及核对页面，不添加空模型。
3. 验证已确认数据在来源变更、父子操作、撤销、权限、导出/分享与并发下的状态。
4. 保留原七类字段的同范围重放和逐条保真，新增类别独立公布结果。若旧摘录解析受
   影响，重放固定 64 文件；源码完全未改时明确给出字节比较，沿用原历史证据，
   不把源码比较说成新的 64 文件执行。
5. 完成实际浏览器、必要 PostgreSQL、本地/CI 所需测试，冻结应用源码并独立审查。
6. 同步公共去标识证据、登记表和入口；校验真实中文 Conventional PR 题目/正文后交付。
   自动版本和发布文档按主线确定的实际版本关联，不手填推测版本。
