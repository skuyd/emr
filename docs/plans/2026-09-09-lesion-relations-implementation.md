## 固定真实验证的取舍

第三次执行保留第一、第二次各自 7 个旧关系映射；新结果为 9 个映射，但没有真实阳性
关系 gold，因此没有建立关联准确率。当前七字段 44 项严格正确，定量 35 项严格正确。
已发表七字段严格正确目标保留 36/37、值正确目标 72/73，最初临床值目标保留 45/46；
同一旧整组侧别目标在这三套集合中均存在缺失。按已经接受的成员范围契约，保留这个
缺失并另列一个未评分的新成员字段，不恢复含义过宽的整组侧别，也不再运行第四次评测。

原门禁仍为 `RETENTION_REVIEW_REQUIRED`。按五批 B1-03 对退化解释取舍的要求继续交付，
不将其改成“全保留”或删除原失败。其他来源片段变化另列；202 个 EXCERPT 完整 payload
保持一致仅证明既定摘录任务保留，不代表全部原始块来源或医学质量已验证。

## 剩余顺序

1. 完成公共文档与实际证据的一致性独审，冻结文档提交和可审查 PR 正文。
2. 在当前分支继续完成历史检查与交付；若 main 发生实质变化，集成已合并 main 并检查
   影响范围，保留旧测试及真实运行身份，仅对新变化做必要验证。
3. 确切 PR 头 CI 与审查通过后 Squash 合并。由 Release Please 计算实际版本并自动发布，
   再按实际版本更新发布清单和引用；不修改任何自动版本字段。
4. 保留真实关系零阳性、范围侧别未独立计分及历史来源差异，继续 B3 其他交付。
   生产状态继续由[发布门禁](../verification/release-gate.md)决定。
