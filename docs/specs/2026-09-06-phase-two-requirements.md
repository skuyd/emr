## 4. 本期需求

### P2-01 指标覆盖与类型清单

- 逐项对照原始方案第 2.3 节，形成“原始条目—稳定编码—标本—结果类型—已有别名—缺口—评测样本”的清单。
- 补齐血常规、肝肾功能、电解质、肿瘤标志物、凝血及尿常规等原始清单中的缺口。
- 同名不同标本、同缩写不同项目使用独立身份；重复名称合并时保留原始清单的对应关系。
  例如血液与尿液的葡萄糖分别识别，PCT 等歧义缩写结合报告上下文判断。
- 已有编码保持稳定，现存基因条目单独记录；覆盖率按确认后的检验项目清单计算。
- 示例中未出现的目标项目使用合成正反例验证功能，并标明真实样本未覆盖；
  合成证据与真实报告来源分别记录，不据合成通过宣称真实解析准确率已验证。
- 数值、比较符、定性、半定量及“未检出/未报告/溶血/拒收”等状态分别表示。
  清单中的派生指标只抽取报告已给出的结果，本期不增加医学公式推算。

### P2-02 版面与字段关联

- 支持单栏、双栏、多表格、重复表头和跨页续表，分别识别项目、结果、单位及参考范围所在列。
- 处理数字和字母混淆、小数点、比较符及上标单位；仅对证据充分的情况产生修复候选，记录转换前后内容。
- 每个发布字段可定位来源文档、页码及对应区域；只有页面定位时明确展示降级状态。
- 分栏或行列关联无法确定时保留原件、OCR 和候选，记录失败原因，进入重试或复核流程。
- 解析器实现由后续设计选择，本期需求不预先绑定新的云模型或多模态供应商。

### P2-03 自动校验与疑似识别错误处理

- 分别校验字段类型、单位量纲、项目与结果关联、报告内部一致性、与既往记录的差异和来源置信度。
- 规则包含适用项目、前置条件、规则版本和触发原因；缺少可比依据时不执行历史差异校验。
- 保留“识别不确定”“字段关联冲突”“单位不明”“参考范围不明”等可解释原因。
  本期的高风险路由指识别错误风险，不生成疾病风险等级。
- 疑似错误保留原始数据，暂停其参与依赖该字段的趋势或范围对照，允许重新识别或复核。
- 原始需求中的校验公式、固定比例和阈值作为候选规则，经过单位与适用条件校准后再启用。

### P2-04 用户核对与可选更正

- 在详情对照视图展示待核对字段及原件定位，提供“与原件一致”“识别有误”“暂不处理”。
- “识别有误”可以直接反馈；用户也可主动更正日期、项目、结果或单位，填写正确答案不是必需操作。
- 用户无需逐字段确认即可完成归档、搜索和原件查看；普通可靠结果不制造批量校对待办。
- 用户确认只记录与原件的核对，不能自动绕过单位、日期、来源和可比性检查。
- 更正保留作者、时间、前后值和来源；支持撤销，界面区分自动结果与人工修订。

### P2-05 受控复核工作流

- 提供内部复核队列，支持待分配、处理中、已完成、无法判断、已撤销，并记录状态变化。
- 复核人员只能访问明确授权任务内的资料及所需来源；授权撤回、原件删除后停止访问和提交。
- 支持原件对照、确认、更正、标记无法判断；纠正的是资料转录和映射，不提供诊疗判断。
- 复核状态与 OCR 置信度分别记录。复核可解除已核实的具体错误原因，保留原始分数；
  其余来源、单位和可比性条件仍须满足。
- 原件删除或解析版本变化时，阻止过期任务将结果写到新版本；并发修改须检查版本冲突。
- 本期验收交付工作流和权限行为，使用隔离测试角色；真实复核人员的招募及服务运营另行安排。

### P2-06 指标字典审核与版本发布

- 未命中的项目、别名和单位进入候选集合，支持核对来源、去重、冲突检查、接受或拒绝。
- 涉及单位换算、可比性或校验规则的变更须记录适用条件、审核者及依据。
- 候选经过审核与回归评测后发布不可变版本，支持查看差异和回退。
- 任何自动映射只产生候选，不直接改写正式字典；字典证据与审核访问遵守资料授权范围。
- 发布新版本后可选择对历史资料重新整理；旧结果和使用过的规则版本可追溯。

### P2-07 可靠纵向对比与参考范围对照

- 提供“指标为行、检查日期为列”的多列对比，支持项目分组和时间筛选，每个值可回到原件。
- 每次检查独立保留，同日多份结果不静默平均、去重或选择一份替代。
- 依据项目、标本、单位、方法及来源质量分组，展示可直接比较、经规则换算、依据不足三种状态。
  依据不足的记录可以并排查看，但不连为同一趋势、不计算跨记录变化比例。
- 单位换算只使用已审核的项目级规则，同时保留原始值、原始单位、换算值和规则版本。
- 只按报告自身明确且可信的参考范围显示“低于/范围内/高于”；参考缺失或冲突时显示无法对照。
- 定性、半定量、带比较符和状态值保留自身语义，使用适合的表格表达，不当作普通精确数值连线。
- 本期不将偏离比例解释为病情严重程度，不自动套用人群默认参考范围。

### P2-08 评测集与质量报告

- 建立固定、版本化的标注集和独立评测流程，覆盖原始清单及双栏、错位、单位混淆、参考范围和特殊结果类型。
- 开发使用用户现有示例及合成样本；真实准确率只在具有可信标注的真实示例上计算，
  记录样本范围及覆盖限制，合成样本和真实样本分别统计。
- 标注包括项目、标本、结果、单位、参考范围、日期、来源位置和不可判断项；独立标注后处理分歧。
- 将现有示例按独立报告归组并冻结为固定回归集。同一报告的图片、PDF、重复拍照和页片段归入同一组。
  已用于字典提取或调试、或者无法确认使用历史的样本，按开发回归样本记录。
- 如有能够确认尚未参与调试的报告，可按整份报告留出评估；缺少这样的样本不阻止本期功能验收，
  但不能把开发回归结果称作独立泛化评估。同时报告患者、机构、版式和指标覆盖。
- 每次解析、字典或规则发布产生可重复的评测报告：全量及成功子集、各类字段的精确率/召回率/F1、
  严重转录错误率、错误拦截率、可用于趋势的比例、耗时，以及与固定基线的变化。
- 失败、拒绝抽取和仅原件样本计入全量口径；没有样本的条目标为未评测。

### P2-09 修订、重解析与来源连续性

- 自动解析结果、用户修订和复核结论分别保留；派生展示明确当前采用哪个版本。
- 新解析版本不得静默覆盖人工修订；来源或值变化时提示冲突，重新完成适用的校验。
- 撤销修订、切换结果版本或字典回退后，列表、详情和趋势按一致规则更新。
- 删除资料时清理相关复核任务、候选证据及派生数据的访问入口，沿用原有删除与隔离契约。

## 5. 验收标准

### 5.1 功能验收

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| P2-AC01 | 指标清单对照 | 原始清单全部条目有映射或明确的拆分/合并关系；每个目标项目通过识别正例与歧义负例；以实际检验条目核算覆盖，基因条目不抵充 |
| P2-AC02 | 双栏与跨页 | 固定回归集中的左右栏无交叉配对，续表字段来源可追溯；不确定关联进入明确降级路径 |
| P2-AC03 | 原值和特殊结果 | 原件与原始字段保留；比较符、定性、半定量和状态不被强制转为普通数值 |
| P2-AC04 | 校验命中 | 预置错行、量级、单位和日期冲突分别触发对应原因及处理路径；可靠对照样本不被同一规则误拦 |
| P2-AC05 | 可选确认 | 不确认仍能归档、搜索、看原件；确认不能绕过剩余质量限制；更正和撤销有记录 |
| P2-AC06 | 复核权限 | 非授权访问失败；撤权、删除、过期版本及并发提交均不能产生越权或覆盖 |
| P2-AC07 | 字典发布 | 未审核候选不影响正式映射；发布前显示差异并通过回归；版本可追踪和回退 |
| P2-AC08 | 可比性 | 可信且满足规则的记录按规则分组；不兼容记录分组展示；缺失、同日冲突及特殊结果保持语义 |
| P2-AC09 | 参考范围 | 只在报告参考明确、结果可对照时生成陈述性标记；缺失或冲突显示无法对照 |
| P2-AC10 | 来源与修订 | 对比值、修订和复核结论均可回到对应来源；重解析不会静默覆盖人工内容 |
| P2-AC11 | 评测复现 | 相同样本、标注、解析器及规则版本可复现指标；报告包含完整分母、失败和未评测范围 |

### 5.2 现有示例的验收口径

2026-09-06 本地盘点：示例目录共有 64 个支持格式文件，分别为 20 个 PDF、34 个 JPG、
10 个 PNG；20 个 PDF 合计 80 页。按完整文件 SHA-256 未发现完全相同的文件。
盘点依据见[示例文件清单](../verification/artifacts/phase-two-sample-inventory.json)，只包含
文件哈希、格式、大小和 PDF 页数，不包含患者姓名、源文件名或医疗正文。

文件数与页数不等于独立报告数；同报告多页、重拍和图片/PDF 副本需在标注前按内容归组。
初次盘点尚未确认独立报告数、检验报告数或标注量，不能用 64 或 80 直接充当准确率分母。
后续实施已完成分类、双轮标注及分歧裁定；实际分母与统计方法见
[第二阶段验证记录](../verification/phase-two.md)，不改变本节验收口径。

| 项目 | 本期验收要求 |
| --- | --- |
| 样本规模 | 使用现有示例，不设 200 份或其他最低报告数量门槛；后续新增资料作为增量样本另行记录 |
| 样本范围 | 固定全部现有文件清单；逐份记录文档类型、报告组、是否可标注及排除理由，检验指标仅在相关报告上评测 |
| 功能覆盖 | P2-AC01 至 P2-AC11 全部执行；真实资料缺少的错行、单位、特殊值、删除和权限场景使用合成用例补足 |
| 真实解析质量 | 在实际有标注的检验示例上报告正确数、错误数、漏抽数、分母及精确率/召回率/F1，并与冻结基线比较 |
| 严重错误处理 | 固定验收集中已知的指标错配、比较符丢失、量级和单位转换错误，须修复或进入明确的疑似错误路径，不得作为可靠结果发布 |
| 覆盖与回归 | 失败与拒绝抽取继续计入全量口径；关键字段召回率不得低于同一固定集的基线，防止通过减少抽取来美化错误率 |
| 缺少真实样本的项目 | 字典定义及合成正反例可以完成功能验收，真实准确率保持未验证；不要求用户逐项提供真实报告 |
| 小样本结论 | 指标同时展示整数计数和适用样本范围；未覆盖项不填 0% 或 100%，不据当前样本声称跨机构普遍效果 |

现有示例集可以用于反复回归；只有明确未参与开发且未泄漏的报告才称为留出集。
本期可以完成“功能验收通过、现有示例回归通过”的交付结论，同时保留未覆盖领域的
真实质量限制，不需要等待补齐大规模报告。

### 5.3 质量改进目标

原始需求第 3.2、7 节的数值保留为质量优化目标。当前样本的指标须如实报告；
样本不足时不把这些目标当作总体准确率的统计证明，也不作为额外招募报告的前置条件。
本期交付按第 5.1、5.2 节判定，优化目标未达到时记录差距及对应的降级范围。
核心/扩展归属经 P2-01 去重和歧义核对后固定，不能在看到评测结果后调整分组。

| 指标 | 建议目标与口径 |
| --- | --- |
| 检验结果 F1 | 核心集合 ≥95%，扩展集合 ≥90%；项目、结果类型、结果和单位联合匹配，按全量标注计算 |
| 严重转录错误率 | <0.5%；发布结构化结果中指标错配、比较符丢失、量级或单位转换错误的条目占比；同时报告绝对数量 |
| 量级错误拦截召回率 | ≥90%；固定错误样本中被规则送入疑似错误路径的比例，同时报告正常样本误拦率 |
| 双栏关联正确率 | ≥95%；以实际评测集中的双栏报告为分母，该报告全部目标行无跨栏错配才算正确；注明是否属于开发回归集 |
| 参考范围准确率 | ≥95%；有明确参考且可标注的字段中，上下界、比较符或参考枚举全部正确的比例，漏提也计失败 |

字段级位置定位成功率及耗时分别报告；无坐标时的页面回退不计为精确定位成功。
观察到零个严重错误只表示本次样本中未出现，不能据此声称总体严重错误率已低于 0.5%。
