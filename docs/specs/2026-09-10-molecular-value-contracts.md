# 分子报告字段值合同

本规格定义解析、核对表单与选定输出共同使用的 `MOLECULAR_VALUE_CONTRACT_V1`，
对应生产模块 [`molecular_contracts.py`](../../apps/facts/molecular_contracts.py)。
报告分段、来源、实体、持久化、修订和消费者链路见[分子应用合同](2026-09-10-molecular-application.md)。
值校验与应用功能均已有验证；纯值校验不证明原件来源或真实识别质量。

## 基本约束

- 保留报告原文字、原单位、比较符、范围、约数、日期精度和各组件的未知状态。
- 类型校验不证明值来自原件，不证明标本或检测归属，不授予确认、导出或分享权限。
- 不根据数值推导 MSI/TMB 定性，不根据基因或药物推导诊断、推荐或治疗记录。
- 值合同与临床共享字段模式、数据库及 PD-L1 评分合同分别管理，不能混用版本或值形状。
- 自动候选、来源核对、修订、搜索、选定导出和分享有独立的应用验证要求。

## 值接口

生产模块为 `apps/facts/molecular_contracts.py`，公开 `validate_value(key, value)` 和
`display_value(key, value)`，字段描述只读。前者对未知字段、缺键、多键、类型错误及不一致
结构抛出 Django `ValidationError`，不改变传入数据；后者先校验，再保留报告原表达。
该显示结果是普通文字，HTML 消费者仍按框架默认进行转义。

| 值族 | 必须保留或拒绝的行为 |
| --- | --- |
| 原文组件 | `PRINTED`、`NOT_PRINTED`、`UNKNOWN` 分开；已印必须有原文，其余不能包含猜测文字。未印需要应用层原件范围证明，校验器本身不生成证明 |
| panel 与方法 | 名称、方法原词；规模保留整数文字、原计数对象/单位、比较符、范围、约数；不能解析的原断言保持未知数值，不能补零 |
| 检测日期 | 采样、收样、报告为三个独立字段；年、月、日和未知精度不互相填补，拒绝不存在的日期 |
| 变异身份 | 小变异、拷贝数、融合使用不同严格形状；保存原基因或位点、完整表达、已印编码/蛋白位点、带版本转录本、位置和体细胞/胚系/未知范围 |
| 融合伙伴 | 保留伙伴原顺序及各自转录本/断点；未印方向保持未知，不按字母排序，也不从连字符推断融合 |
| 分子数量 | 非负有限十进制字符串、`EQ/LT/LE/GT/GE/RANGE`、原单位状态、测量种类和约数；布尔、NaN、无穷、倒置范围拒绝；缺单位不能补百分号或转换比例 |
| MSI/TMB | MSI-L 不并为 MSS；类别、数量、TMB 定性各自保留，不互相推导，也不将参考阈值作为患者值 |
| 报告药物证据 | 原有序药名与明确组合关系、报告方向、等级及等级体系；未印体系保持未知，不跨体系排序，不从“未见耐药”推成获益 |

具体 JSON 键由模块公开合同及合成输入示例定义；来源窗口、断言作用域和真实父实体约束
由应用合同单独验证，不能只调用本模块就把一个字段标记为可用。

模式标识为 `MOLECULAR_VALUE_CONTRACT_V1`。单组件使用 `{state, raw}`，重复组件使用
`{state, values}`，保留顺序和重复项。数量使用 `{status, values, comparator, unit,
unit_state, approximate, measurement_kind, assertion, raw}`；panel 规模另含
`count_object` 原文组件。`UNRESOLVED` 必须是空数值列表和空比较符。
三个日期均使用 `{value, precision, raw}`；应用适配将 `raw` 映射到既有共享日期的
原文外层，不能用这一纯值输入替换已发布的日期持久化形状。

变异的 `COMPLETE/INCOMPLETE` 只描述声明的身份组件是否完整，不表示来源已核实或
临床结果可用。`display_value` 对缺失单组件返回空文字，调用者必须另行显示其保存的
`NOT_PRINTED/UNKNOWN` 状态。校验器不判断 `raw` 与枚举或数值的原件语义是否相符；
这种一致性、来源精度和患者结果作用域必须由提取、核对和持久化链路验证。

## 验证与边界

[`tests/facts/test_molecular_contracts.py`](../../tests/facts/test_molecular_contracts.py)
覆盖原字符保留、缺失状态、完整身份差异、有序伙伴、日期精度、未解析计数、数值边界、
非法形状以及不改变输入；兼容性回归覆盖既有临床基础和影像数量字段。
实际结果见[值合同验证](../archive/verification/molecular-value-contracts.md)。

实际上传、持久化、迁移、租约、来源核对、修订及派生输出失效由
[完整应用验证](../archive/verification/batch-three-molecular-application.md)证明，不能由本模块的测试替代。
真实分子 M7 评估未启动，未读或未标注资料继续为未判断。
