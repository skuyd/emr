## 1. 目标与范围

本次覆盖三项优化：

1. 按示例 Excel 的分类和指标顺序选择检验对比内容，支持整类或部分指标选择，只展示选中的指标。
2. 隐藏重复的单来源入口，紧凑展示多个来源，同时保留数值链接及必要的核对提示。
3. 支持勾选多份完整检验报告，一次确认其中符合条件的待确认结果，减少逐项操作。

适用对象为当前患者的检验对比与报告结果核对流程。现有指标身份、别名、标准单位、参考范围、报告归并、权限及修订审计规则继续适用，局部调整见第 6 节。

## 3. 功能需求

### R1：按分类和指标选择检验对比内容

- 下拉选择和对比表均按 Excel 中的分类、指标顺序排列，本页不再受现有个性化指标排序设置影响；其他页面的排序规则不在本次调整范围内。
- 下拉选择采用“分类 → 指标”的树形结构，只列出当前患者已有检验记录的项目；表外项目统一放在末尾的“其他”。
- 支持选择一个或多个分类，也支持只选择分类下的部分指标。整类勾选选中其全部指标，取消分类勾选取消其全部指标，部分选中时分类显示半选状态。
- 下拉框内的分类可展开、折叠；对比表继续支持分类折叠。折叠仅影响展示，不改变选择。
- 首次进入默认全选。手动取消全部选择并应用筛选后，显示未选择指标的空态，不恢复为全部显示。
- 点击现有“筛选”按钮后生效，对比表只显示选中且符合日期、关键词条件的指标；没有可显示指标的分类不占位。
- 查看结果详情后返回，保留原筛选条件。
- 延续既有指标别名、身份及历史归并规则，不因新增选择器重复生成同一指标的历史行。

### R2：隐藏单来源入口，紧凑展示多来源

来源数量按当前展示结果关联的来源记录计算，沿用现有结果折叠与来源保留规则。

| 来源数量 | 展示规则 |
| --- | --- |
| 只有 1 个来源 | 一律隐藏“1 个来源”文字和独立来源入口，与是否核对无关 |
| 多于 1 个来源 | 保留紧凑的“X 个来源”折叠入口，减少边框和留白 |

所有结果的数值链接继续保留。点击数值进入现有检验结果核对页，可查看嵌入的原图、原始结果及来源信息。

来源入口的隐藏不改变核对状态，不隐藏既有待核对、识别有误或冲突提示。即使单来源结果尚未核对或存在冲突，也不重新显示“1 个来源”。多来源展开后仍可查看各来源的采样时间、报告号、原结果及原图依据，桌面和手机均可操作。

### R3：按多份完整报告批量确认检验结果

#### 3.3.1 入口与选择范围

- 从检验对比页进入报告批量确认列表，支持勾选多份报告后一次提交确认；只选一份时同样可使用。
- 选择对象是已归并的完整报告，包含已明确关联的续页及重复来源。上传文件、单页报告单元和对比表中的同日同院列均不等同于完整报告。
- 不因对比表中数值相同或同日同院而扩大确认范围，不自动纳入所选完整报告以外的结果。
- 提交前展示各报告的待确认、已确认及需要跳过的项目数量，并可展开查看项目和来源，明确本次确认范围。

#### 3.3.2 确认与跳过规则

- 按用户 2026-09-27 的变更，单项和批量“与原件一致”均表示该结果的标本、指标和结果已经人工核实，记录逐项核对状态和操作历史，不修改检测数值。
- 已确认结果不重复处理；已标记“识别有误”、存在修订冲突或报告归属冲突的结果跳过，并列出数量、原因及处理入口。
- 普通待核对状态不作为跳过条件。当前有效确认解除相应标本、指标和结果待核对提示，以及仅因尚未人工核实造成的质量限制；单项与批量确认效果一致。
- 历史已有的当前有效 `CONFIRM` 记录直接按上述含义生效，无需迁移或要求用户重新确认。撤销确认后，按撤销后的有效记录恢复核对提示与质量限制；更正或重解析出现内容冲突时，不将旧确认应用到冲突内容。
- 确认不生成实际缺失的标本、单位、日期、检测方法或标准指标等信息，不改写原始质量记录。依赖这些信息的展示或计算仍检查真实数据和适用规则；缺少必需信息时明确说明缺项，不用“待人工核对”代替缺项说明，也不任意放开趋势、对比或派生计算。
- 被跳过项目的错误标记、冲突状态及原始记录继续保留。部分项目被跳过时，明确显示尚未完成确认的项目，不将整份报告标为全部已确认。
- 批量结果确认不更改医院、采样时间、报告号或报告合并关系。
- 保留原有逐项核对与更正能力。

#### 3.3.3 权限、版本与审计

- 沿用患者写权限和修订审计规则；没有写权限的用户不能执行批量确认。
- 提交时复核当前报告及结果版本，发生内容变化时提示刷新，不确认过期内容。
- 重复提交不重复生成确认记录；确认范围和完成数量与实际处理结果一致。

## 4. 验收标准

以下为功能验收要求，实际覆盖及执行结果见[验证记录](../verification/lab-selection-batch.md)。需求文档校验不能代替功能验收。

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| AC-01 | 比较下拉框、对比表与当前确认哈希的 Excel；患者仅有部分目录指标及表外指标 | 两处遵循 22 分类、201 源条目的分类和指标顺序；只列有记录的项目，“其他”在最后；不恢复已移除分类或重复分类 |
| AC-02 | 整类选择、跨分类选几项 | 只展示所选指标，分类半选状态正确，不重复生成同一指标的历史行 |
| AC-03 | 展开或折叠下拉框及对比表分类 | 不改变已选项目 |
| AC-04 | 首次进入、手动清空、重新选择 | 分别显示全部、空态、重新选中的内容；空分类不占位 |
| AC-05 | 日期和关键词筛选、详情返回 | 筛选组合正确，返回后条件保留 |
| AC-06 | 单来源结果分别处于未核对、已核对、识别有误和冲突状态 | 均不显示“1 个来源”；数值链接和必要状态提示保留，可从数值进入原图核对页 |

| AC-08 | 勾选一份或多份含续页和重复来源的报告 | 覆盖所选完整报告，不扩大到同日同院或其他未选择的报告 |
| AC-09 | 混合待确认、已确认、有误和冲突项目 | 只确认符合条件的项目，准确展示跳过原因和剩余项；部分跳过时不标记整份报告全部已确认；解除被确认项目的人工质量核对限制，实际计算前提仍检查 |
| AC-10 | 无写权限、重复提交、提交前发生修改 | 正确拒绝越权，不重复确认，不写入过期确认；操作留下既有修订审计记录 |
| AC-11 | 分别执行单项和批量“与原件一致”；读取历史有效 `CONFIRM` | 标本、指标、结果均视为已人工核实；相应待核对提示及人工质量核对限制解除，历史确认无需迁移或重新提交 |
| AC-12 | 已确认结果仍缺计算所需的标本、单位、日期、方法或标准指标 | 显示实际缺项，不虚构字段；仅在真实数据和适用规则满足时执行相应计算 |
| AC-13 | 撤销确认 | 按撤销后的有效记录恢复原核对状态、提示及质量限制，原始记录不变 |
| AC-14 | 确认后更正或重解析出现内容冲突 | 不误用旧确认解除新内容的限制；批量确认继续跳过识别有误、修订冲突和报告归属冲突 |
