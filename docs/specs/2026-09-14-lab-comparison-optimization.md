# 检验对比需求规格

本文定义当前检验对比页面的查询、指标选择、结果表格与来源核对规则。交付状态以[文档登记表](../document-registry.json)为准；生产放行以[发布门禁](../verification/release-gate.md)为准。

## 1. 目标与范围

用户能够按日期和指标查看历次检验结果，辨认检测医院、参考范围及有依据的异常提示，并从结果返回原件核对。

页面保留日期和关键词查询、分类及指标选择、结果表格和表格内来源入口。页面没有趋势开关、趋势列、独立单位列、顶部辅助说明或检验工作区导航。健康趋势、多指标对照及跨报告批量确认已退出当前功能范围。

相关职责分别由以下规格定义：

- [固定检验指标目录与患者适用参考范围](2026-09-22-lab-indicator-catalog-and-reference-ranges.md)：标准名称、分类顺序、单位和参考范围。
- [检验报告上传校验、报告归并与结果去重](2026-09-17-lab-report-consolidation.md)：报告身份、日期医院合列、结果折叠和来源保留。
- [检验报告逐份核对确认](2026-09-28-lab-report-review-workspace.md)：当前一份报告的原图、改错、补漏、保存和确认。
- [检验报告 OCR 异常处理规则](../policies/lab-ocr-exception-rules.md)：单位规范化、人工确认与实际计算限制。

## 2. 查询与指标选择

### 2.1 日期与关键词

- 搜索标签为“检验指标”，输入提示为“输入指标名称或代码”。
- 在当前患者的有效结果中匹配标准名称、报告原始名称和代码，英文不区分大小写，忽略首尾空格。
- 关键词先确定匹配的指标身份，再显示这些指标在日期及选择范围内的完整历史；已确认属于同一指标的其他别名记录不因名称不同被二次过滤。
- 使用单条关键词包含匹配，不引入拼音、模糊纠错或多关键词语法。未知名称不凭相似片段强行映射。
- 点击“筛选”或在文本框按 Enter 后生效；勾选指标期间不反复刷新页面。
- 开始日期晚于结束日期或日期格式无效时就地提示，保留输入，不显示错误条件下的结果表。
- 无匹配结果时显示“未找到符合条件的检验结果”，提供“清除筛选”；不显示空白表格。

### 2.2 分类与单项选择

- 下拉框为“分类 → 指标”的复选树，只列当前患者已有有效记录的项目。目录内分类、指标遵循固定目录顺序；目录外项目归入末尾“其他”。本页不采用个人排序偏好。
- 可选择一个或多个完整分类，也可只选择分类内部分指标。整类选择或取消作用于该类全部指标，部分选中时分类显示半选。
- 下拉分类和表格分类均可展开、折叠；折叠不改变选择。
- 首次进入默认全选。用户清空后提交筛选，显示“未选择检验指标，请选择指标后筛选”，不自动恢复全部。未知或失效的选择也不能扩大为全部结果。
- 日期、关键词与所选指标取交集。没有可显示指标的分类不占位；没有命中结果的报告列不保留，行内缺项使用“—”。
- 日期或关键词导致暂时无结果时，选择器仍保留该患者可选指标及选择状态。
- 已确认别名、印刷序号和星号按目录身份规则匹配，选择器和表格使用相同分类与身份；不重复生成历史行。
- 筛选结果、刷新、前进后退及来源返回保留患者和查询条件；旧单 `category` 查询继续兼容。
- “重置”恢复全部日期、空关键词和全部指标，保留当前患者。
- 支持键盘、触屏及手机操作，不依赖 Ctrl／Command 多选或鼠标悬停。

## 3. 指标行、报告列与结果折叠

### 3.1 指标行

同一指标及已确认别名集中显示历史结果。目录内使用标准显示名称；未匹配项目按保守的原名规范化归组，不用模糊相似度推断身份。

- 指标展示归组不合并或覆盖数据库中的原始结果、采样事件、来源和有效修订。
- 方法为空、质量状态不同或单位写法不同，不单独把同一指标拆成多行；单位是否等价和结果能否折叠另行判断。
- 计数与百分比仍是不同指标。目录中同名但检测对象不同的项目按明确身份区分，例如尿液颜色与粪便颜色。
- 未映射或存在映射冲突的同名候选可集中展示，但保留指标待核对状态，不因此获得标准身份或折叠资格。
- 每条结果保留其标准代码、标本、检测方法及质量依据。标本和方法不在核对、指标或对比页面展示，也不提示缺失；底层身份消歧及适用规则继续校验。

### 3.2 报告列与表头

- 列按采样日期和检测医院组织；同日同院的不同报告共用一列，不同日期或医院分别成列。日期从早到晚排列。
- 医院来自有可靠关联的结果或报告身份，不从文件名、上传者或邻近报告猜测。
- 医院缺失或归属冲突时保留待核对来源组，不把多个“医院未识别”当作同一家医院合列；日期冲突不强行归入某日。
- 表头上下展示日期及医院。日期的“查看报告”入口列出该列涉及的全部资料，不能假设一列只对应一份原件。
- 医院长名称可以换行，并可通过点击或键盘展开全称；手机不依赖悬停。
- 一份资料包含多份报告、多个机构或多个日期时，使用有证据的报告单元，不能按文件整体猜测归属。
- 机构更正、解析版本切换及来源变更后重新生成表头。

### 3.3 同格多值与来源

同格不同结果全部保留，不取平均、不任选一条覆盖。相同结果只有满足报告归并规格的 DD-01～DD-06 才折叠；视觉归组不能降低身份、单位、质量或来源要求。

| 来源数量 | 展示规则 |
| --- | --- |
| 一个来源 | 隐藏“1 个来源”文字和独立来源入口，不受是否核对影响 |
| 多个来源 | 显示紧凑的“X 个来源”折叠入口，可逐一查看采样时间、报告号、原结果、参考信息及原图 |

所有结果的数值链接均保留。单来源入口隐藏不能隐藏待核对、有误或冲突提示；多来源展开也不能扩大权限。报告数、原图数、来源数与折叠后结果数分别计算，不混用。

## 4. 数值、单位和参考范围

### 4.1 数值与单位

- 显示当前有效的人工修订或自动识别结果，保留精度和比较符，不截断小数，不把阴阳性等文字转成数字。
- 同一行的可见结果单位均可靠一致时，单位随固定首列中的参考范围或指标显示一次。
- 单位不同、未知或有歧义时，每个结果显示自己的单位；不增加右侧单位专列，不把未经确认的单位当成等价。
- 目录内单位规范化、补全和真实换算遵循 OCR 规则；只改写法时不改数值，实际换算必须同时调整数值。保留原值、原单位及来源。
- 筛选改变可见结果集合后，同步重新判断单位显示方式。视觉省略不改变导出和来源中的单位。

### 4.2 参考范围

- 目录内采用患者性别、采样时年龄及本次生理阶段适用的标准参考范围；目录外使用该报告的原始范围。不得从其他患者、医院或相似指标借用范围。
- 非生理阶段指标的范围直接放在固定首列的名称下方，不增加展开按钮或单独参考列。
- 可见报告的相同范围合并，不同范围分别显示并注明日期；日期去重。可解析且界值及包含关系相同的数值范围可合并展示，原文和计算依据仍保留。
- 不能忽略负号、边界包含关系、不同界值或无法解析的附加文字。单位不同时，参考信息也注明对应单位。
- 生理阶段相关指标按每次结果显示自己的阶段及适用范围，不能用某次阶段覆盖整行历史。
- 没有适用标准范围时保留结果，隐藏范围及范围缺失占位；不以原报告高低标记补出目录内标准判断。来源详情仍可保留原报告的缺失信息。
- 范围的视觉去重不代表质量确认，也不解除结果识别、单位或来源限制。

## 5. 异常状态与核对

### 5.1 默认状态

结果值最醒目；有依据时紧随显示 ↑、↓ 或异常文字。偏高使用深红色、偏低使用深绿色，同时提供“偏高”“偏低”的可访问文本，不仅靠颜色区分。

直接影响结果值、单位、类型、参考范围、标记或来源可靠性的问题，使用琥珀色数值与点状下划线，保留“结果待核对”等必要提示。指标身份问题保留“指标待核对”。不逐格展示内部枚举、自动值副本、规则版本和长质量列表。

当前有效的人工确认解除相应已核实字段的待核对提示；撤销确认、更正冲突或重新解析冲突按当前有效状态处理。确认不能补出不存在的单位、日期、标准身份或可用来源。实际缺项和适用限制继续保留，标本和方法不形成页面缺失提示。

### 5.2 判定边界

| 情况 | 行为 |
| --- | --- |
| 目录内结果有可靠标准化值及适用范围 | 使用标准范围判断，不被原报告范围覆盖 |
| 目录内无适用范围 | 不显示基于缺失范围的高低结论，不宣称正常 |
| 目录外有可信报告标记，且与可用范围一致 | 显示对应箭头，保留原标记与范围 |
| 目录外无标记，但可信范围可明确判断 | 高于显示 ↑，低于显示 ↓ |
| 目录外无范围，但有可信且正确关联的高低标记 | 按原标记显示方向并保留依据 |
| 原标记与可靠范围矛盾，或结果/单位/来源存在冲突 | 保留核对提示，不任选一个方向 |
| 结果位于适用范围内且无冲突 | 不反复显示“范围内” |
| 定性、半定量与参考不一致，或只有一般异常标记 | 显示异常文字，不强行使用上下箭头 |
| `>…`、`<…` 等比较符结果 | 只有边界校验可明确判断方向时显示箭头，不把比较符结果当精确数值 |

阳性不自动等于异常；没有箭头也不等于正常。检测方法缺失不单独阻断有可靠依据的参考范围判断。人工更正后重新计算提示，不能沿用旧箭头。

### 5.3 统一核对入口

数值本身链接到所属报告的统一核对页并定位指标，不增加逐格“详情”图标或平行确认表单。链接保留文本选择与复制能力，支持键盘和手机点击，可访问名称包含指标、日期及查看依据的含义。

核对页展示本份完整报告，而非只显示对比页筛选出的指标。历史解析结果保留只读来源能力；分享和导出不跳到可编辑的整份报告。

来源和核对返回时保留当前患者、筛选条件、分类展开状态及阅读位置；原结果因修订或删除移位时，返回对应指标或结果区域。来源读取与每次操作均复核当前患者权限。

## 6. 固定表头与阅读

- 使用一个真实报告表头，各分类为同一表格内的分隔行，共用列宽与横向位置。
- 浏览任意指标时，日期和医院保持可见；左右滚动时固定指标首列及左上角，背景和遮挡层级正确。
- 分类标题显示“分类 · N 项”，默认展开；折叠不改变选择、不跳回水平起点。
- 每种设备只有一个主要纵向阅读滚动面；手机保留指标首列并在报告区域横向滑动，避免页面整体横向溢出。
- 表格区域可键盘聚焦与滚动，固定表头不能遮挡焦点。长机构名、缩放及筛选区域高度变化均需正确布局。
- 离开表格区域时不悬挂孤立表头；来源返回和分类折叠后维持阅读位置。
- 大量报告仍应全部可访问，不为速度静默截断结果。

## 7. 验收与限制

| 场景 | 可验证结果 |
| --- | --- |
| 名称、代码、已确认别名搜索及日期错误 | 身份历史完整，错误保留输入，患者范围不变 |
| 分类整选、部分选、清空、重置及未知选择 | 半选正确；首次为全部、显式清空为空；目录顺序稳定 |
| 日期和关键词筛选后查看选择器、返回来源 | 选项和查询保留；无结果分类及报告列不占位 |
| 同名候选、计数/百分比、尿液/粪便颜色 | 身份边界明确，无错误合并或来源覆盖 |
| 同日同院多报告、不同医院、身份或时间冲突 | 合列符合规则，全部来源可追溯，未知医院不误合列 |
| 单来源的未核对、已核对、有误、冲突结果 | 均无“1 个来源”，必要状态与数值链接仍可达 |
| 多来源、不同数值、参考信息差异 | 多值完整；折叠条件严格；来源与差异可查看 |
| 单位一致、混合、未知或筛选改变单位集合 | 单位随指标或结果正确显示，无独立单位列 |
| 不同标准范围、生理阶段、缺少适用范围 | 范围位置与去重正确；缺范围不显示占位或虚构高低 |
| 标记冲突、边界值、比较符及定性结果 | 箭头有来源，未知不当正常，精度及原文保留 |
| 核对、指标及对比页面 | 不展示标本、方法或其缺失提示，底层身份和质量限制仍成立 |
| 桌面、360 px 手机、200% 缩放和键盘浏览 | 表头及首列对应，无页面横向溢出，焦点与来源返回可用 |
| 查看当前对比页 | 无趋势控件、趋势列、重复单位列、顶部说明或辅助导航 |
| 修订、重解析、删除来源、切换患者及撤权 | 结果与状态同步更新，无越权或失效来源泄露 |

现有功能证据见[对比验证](../archive/verification/lab-comparison-optimization.md)、[选择与来源验证](../archive/verification/lab-selection-batch.md)及[页面精简验证](../archive/verification/feature-pruning.md)。这些记录限定各次执行范围，不表示当前版本已通过生产容量验收。

大量数据的滚动与响应验收使用不少于 100 个指标行、50 个报告列的合成数据及固定浏览器环境，记录硬件、数据量与实际耗时；未经测量不能声称达到性能目标。文档整理不重新运行或改变业务验收结论。
