## 1. 产品目标与范围

用户打开检验对比后，应能快速回答：某个指标历次结果分别是多少、在哪家医院检测、
哪些结果被标记为偏高或偏低，以及哪些记录能用于观察变化。

本期完整覆盖八项反馈，不把其中任何一项作为可选的后续需求：

| 编号 | 用户反馈 | 产品决策 |
| --- | --- | --- |
| LC-01 | “项目”不清楚，缺少输入提示 | 改为“检验指标”，提示“输入指标名称或代码” |
| LC-02 | 同一指标在不同报告中被拆成多行 | 按指标身份组织展示行，独立判断趋势可比性 |
| LC-03 | 依据、自动识别等信息占据过多空间 | 默认突出结果与必要状态，不逐格显示“详情”；点击数值访问现有核对页 |
| LC-04 | “迷你趋势”含义不明 | 改为“变化趋势”，默认收起，通过一次页面级开关按需显示 |
| LC-05 | 标题行缺少医院 | 每个报告列表头显示日期、检测医院和报告入口 |
| LC-06 | 分组只能单选 | 支持复选、多组并集筛选，并保留筛选状态 |
| LC-07 | 查看后面的指标时看不到标题 | 共用报告表头，固定表头和首列，避免页面与表格双重纵向滚动 |
| LC-08 | 异常指标不醒目 | 结果旁显示 ↑／↓；无方向的异常使用文字标记 |

本期涉及检验对比页面、筛选、展示分组、趋势摘要和现有结果核对入口。暂不新增诊疗建议、
自动纠正原报告、全新的单位换算规则、指标人工合并工具或新的导出功能。

页面标题统一为“检验对比”。工作区导航不重复显示当前页同名入口；全站导航保留。页面顶部保留当前患者及现有排序设置。

```text
检验对比
日期范围 · 检验指标搜索 · 分组多选 · 筛选／重置 · 显示趋势

检验指标       2026-08-01     2026-09-01       单位
               示例医院 A    示例医院 B
血常规 · 2 项
合成指标甲     5.2           11.2 ↑           10^9/L

合成指标乙     0.02          0.03             10^9/L

```

上图中的数值和范围均为合成示例。日期本身链接报告，数值本身链接该结果的现有核对页，
不额外重复“查看报告”“详情”等文字。单位不同或不明的行按第 6 节逐值显示单位。

“日期未识别”。指标按现有分类与个性化排序排列；本期不自动把异常行移到最前，避免阅读位置跳动。
统计分别计算去重的指标行数与报告数；同份报告含多个检查日期时，可产生多列，但报告只计一次。

## 4. 搜索与分组筛选

### 4.1 检验指标搜索

- 标签：**检验指标**；输入提示：**输入指标名称或代码**。
- 在当前患者的有效结果中匹配标准名称、报告原始名称和代码，英文不区分大小写，忽略首尾空格。
- 关键词先确定匹配的指标身份，再展示这些指标在日期及分组范围内的完整历史。
  已确认属于同一指标的其他名称记录不能被关键词二次过滤掉；未映射候选仍遵守归并边界。
- 示例输入包括“嗜碱性粒细胞”“白细胞”和已有代码；不承诺尚未建立映射的任意缩写可被识别。
- 本期采用单条关键词包含匹配，不引入拼音、模糊纠错或多个关键词的特殊语法。
- 点击“筛选”或在文本框按 Enter 后生效；分组勾选期间不反复刷新页面。
- 保留开始及结束日期；开始晚于结束、日期格式无效时就地提示并保留输入。
- 无结果时显示“未找到符合条件的检验结果”，提供“清除筛选”，不展示空白表格。

### 4.2 分组多选

采用带复选框的分组下拉面板，避免要求用户使用 Ctrl／Command 才能多选。

- 默认不限制分组，按钮显示“全部分组”；面板只有具体分组的复选项，不设置相互排斥的“全部”复选框。
- 选中多组取并集，例如血常规或肝功能；日期、关键词与分组之间取交集。
- 面板说明“不选则显示全部分组”。取消最后一项后保持全部未勾选，按钮显示“全部分组”；
  提供“清除选择”操作。只在用户提交筛选后应用，不自动勾回已取消的项。
- 收起时显示已选名称；超过两项时显示前两项及“等 N 组”，展开可见完整勾选列表。
- 分组选项来自当前患者的有效结果，并保留当前已选项；不因关键词暂时无结果而丢失勾选。
- 提供“未归类”以访问尚未归入标准分组的结果。
- 字典中的 `CBC` 和 `HEMATOLOGY` 均显示为“血常规”，界面合为一个选项并筛选两类，
  避免两个同名选项和两段同名标题。其他别名按显式映射处理，不仅凭显示名称自动合并。
- 筛选结果、刷新、前进后退均保留日期、关键词、分组及患者范围；旧单分组链接继续有效。
- “重置”恢复全部日期、空关键词及全部分组，保留当前患者和其排序偏好。
- 仅展示筛选命中的报告列，无命中结果的列不保留；多指标之间缺项用“—”占位。

键盘可打开面板、切换复选框及关闭面板；Escape 关闭并把焦点还给分组按钮。
手机使用相同复选行为，不依赖桌面多选快捷键。

## 5. 同一指标的归并规则

### 5.1 展示行与计算分组

**一行用于找到同一检验指标；是否能连成趋势，由该行内每条记录的可比依据决定。**

按用户 2026-09-21 的后续确认，以“当前患者＋展示名称”确定展示行；名称使用原名及已有审核别名，
清除序号、装饰字符，不使用模糊匹配推定指标。同名结果集中一行，即使标本不同、未知或指标尚待核对。
标本和待核对状态逐条放在结果旁；单位、方法、医院和可信状态作为结果属性。
归并只是读视图的组织方式，不修改或合并数据库中的原始结果。

| 场景 | 表格展示 | 趋势与变化计算 |
| --- | --- | --- |
| 同一标准指标，不同报告名称或已确认别名 | 放同一行 | 按指标可比规则判断，方法缺失按第 5.3 节处理 |
| 同一指标、同一明确标本，方法缺失／不同或质量状态不同 | 放同一行；方法缺失不显示提示，仅保留必要的结果质量状态 | 缺方法由指标规则判断；已知不同方法没有明确等价依据时分系列 |
| 同一指标、单位大小写或排版不同且已由字典确认等价 | 放同一行；可规范显示，详情保留原文 | 等价写法按明确规则统一 |
| 同一指标、单位不同或写法存在歧义 | 放同一行，每个结果保留自身单位 | 无已审核换算规则时分系列或不计算 |
| 同名但属于计数和百分比，例如嗜碱性粒细胞计数与百分比 | 分开为两个指标 | 各自独立 |
| 同名但属于血液和尿液指标 | 同一行，每条结果用中文明确标本 | 各自独立 |
| 标本未知且无法确认与现有行一致 | 同名集中一行，逐结果标明“标本待确认” | 不猜测归入血液或尿液系列 |
| 未映射或映射冲突的候选项目 | 同名集中一行，逐结果标明“指标待核对”，来源保留原名；仅相似但不同的名称不合行 | 不提升身份确认、结果折叠或计算资格 |
| 同一报告内同一指标有多条结果 | 同一格完整保留，必要时标页码或标本 | 不取平均、不静默覆盖；歧义沿用既有阻断规则 |

展示行不代表标准代码等价：每条记录保留自身代码、标本、质量问题和来源。
同名行只有一个已知类别时归入该类；多个已知类别冲突时放入“未归类”，不任取一类。
按任一原类别筛选仍能找到整行历史；分类冲突不使正确记录从原类别筛选中消失。
同名不放宽结果折叠或趋势资格；多个可绘图代码分别提供趋势入口，不跨身份连线。

### 5.2 用户示例的目标效果

当多个报告的结果都确认属于“嗜碱性粒细胞计数”、标本一致时，应只有一行，
每个报告日期下分别显示对应数值，即使方法未识别或可信状态不同。

`BLOOD · ×109/l · 方法未识别` 不再默认紧跟指标名称展示；方法移入详情。
每条结果旁显示“血液”“尿液”“标本待确认”等中文标本。

`×109/L` 可能涉及指数排版丢失，仅凭字符串不能认定为 `×10⁹/L`。未经明确字典规则或核对，
保留原单位并阻止相关计算；这一歧义本身不必把已确认身份的同一指标拆为多个主行。

### 5.3 检测方法的作用（用户已确认）

**检测方法属于辅助判断信息，缺失本身不打扰用户、不妨碍结果集中展示；只有确实影响比较时才参与限制。**
此原则已在本轮讨论中获得用户确认，属于本期要求，不再仅作为后续研究建议。

| 使用场景 | 确定规则 |
| --- | --- |
| 主表显示 | 没有注明就不显示，不生成“方法未识别”或仅由此造成的“待核对” |
| 同指标归并 | 不因方法为空拆行；有方法的结果和无方法的结果可归入同一已确认指标行 |
| 异常箭头 | 依据本份报告的可信标记或参考范围判断，不单独要求方法字段非空 |
| 历史展示 | 保留历次结果；数值、日期和单位等绘图依据可靠时，可显示尚未确认可比的独立数据点 |
| 连线及派生计算 | 按指标审核的可比规则判断；规则可明确接受方法缺失，不使用全局“方法非空”门槛 |

“未注明方法”只表示该信息未取得，不推定所有报告方法相同，也不推定该指标不受方法影响。
实验室方法和参考范围可能不同，相关背景见
[美国国家医学图书馆的检验结果说明](https://medlineplus.gov/lab-tests/how-to-understand-your-lab-results/)。
这里的产品决策是在信息缺失时保持展示可用，不是证明这些结果可以互换。

允许方法缺失的计算规则须明确适用指标、标本、单位、机构范围及其他必要条件，
并保留审核依据和规则版本。没有适用规则时保留结果及符合绘图条件的独立点，不默认连线、
不计算跨记录变化率或个人均值；解释集中在趋势页，不逐格输出缺方法提示。
医院相同或单位相同都不能单独替代可比规则。实际方法已注明且存在差异时，仍按规则检查。
本方案不预先声明哪些具体指标已获准放宽；实施时用相应规则和样例验证。

## 6. 信息精简与按需核对

### 6.1 默认可见内容

每个结果格默认只显示：

1. 有效结果值，结果值最醒目；单位按下述规则集中或逐值显示。
2. 有依据时显示 ↑、↓ 或“异常”；影响本结果可靠性的情况用琥珀色数值和点状下划线标记，并显示“结果待核对”。
3. 按 2026-09-21 的确认逐结果显示标本；标本未知或指标身份存在疑点时显示对应核对提示。

**不在每个指标或结果旁显示“详情”“查看来源”、信息图标、更多菜单或悬停后新增按钮。**
数值本身作为现有结果核对页的链接，保留文本选择和复制能力；桌面悬停／键盘聚焦时加下划线，
手机可直接点击，交互区不能小到难以点按。辅助技术名称应包含指标、日期及“查看结果依据”。
页面帮助中仅说明一次“点击数值查看依据，点击日期打开报告”，不增加每行说明。

按用户 2026-09-15 提供的本地演示文稿第 3、4 页调整：若当前行所有已显示结果的单位均已确认一致，
单位在各报告结果右侧的“单位”列只显示一次；固定首列集中显示指标名称，标本按上述后续确认逐结果显示。
存在不同、未知或有歧义单位时，该行全部结果各自携带单位，避免混读；缺失单位显示“—”，需要确认的数值沿用琥珀色提示。
不把尚未确认等价的原文当成一致单位。筛选引起行单位展示方式变化时，单位与数值必须同步更新。
复制单个数值允许只复制原数值；若未来增加结构化复制／导出，不得因视觉去重漏掉单位。

按用户确认，原始参考值直接放在固定首列的指标名称下方，不使用按钮或展开交互，也不另设右侧列。
当前可见报告的范围一致时只显示一行“参考：范围”；范围不同则逐行显示不同值并注明对应报告日期，
相同范围合并、合并后的日期去重，同日重复报告沿用表头的报告编号。可解析且上下界及包含关系相同的数值范围允许合并展示，保留首个原文；非负上下界之间的双横线仅作展示分隔识别，不改写来源或计算依据。负号、包含关系、不同界值及无法解析的附加文字不得忽略。单位不同时随参考值注明单位，
单位缺失写“单位未提供”；没有参考值写“参考：未提供”，不从其他报告、演示稿或通用范围补齐。
筛选变化后重新按可见报告汇总。显示的是原报告参考文本，去重不表示质量确认或医学可互换；
异常方向、质量颜色及趋势资格继续使用每份报告原有的校验结果。

正常结果不反复显示“范围内”；方法缺失本身不显示提示，也不单独标记结果待核对。
仅在用户查看受限计算的依据时解释对应规则所需信息。单元格琥珀色提示仅用于直接影响
结果值、单位、结果类型、报告标记或参考范围的问题，例如相关字段识别不确定、来源不可用及关联冲突。
日期、检测方法或质量策略版本等说明保留在点击数值后的核对页，不单独触发单元格提醒。
按 2026-09-21 的确认，指标映射和标本问题逐结果显示“指标待核对”，未知标本显示“标本待确认”；
直接影响结果的问题在原有琥珀色基础上显示“结果待核对”，具体原因仍在核对页。
未说明影响字段的问题仍保守提醒；缺少参考范围本身不触发提醒。隐藏单元格提醒不放宽异常或趋势
计算资格，没有箭头不能被表述为“正常”。此范围按用户 2026-09-15 的后续反馈收窄。

结果值使用当前有效的人工修订或自动识别结果，不在主表重复显示“本次自动”。
数值和单位原有精度保留；不要为了缩短内容把小数截断或把比较符删除。

## 7. “变化趋势”的定义与展示

原来的“迷你趋势”是同一指标在不同日期的数值变化小图，用户无须理解“迷你”这一术语。
列名改为**变化趋势**。页面级“显示趋势”开关默认关闭，开启后才增加行尾趋势列；
开关状态在当前患者页面刷新及返回时保留。页面帮助说明：“查看同一指标随检查日期的变化；
仅连接可比较的结果。”

- 开启后趋势图放在行尾，不逐格重复个人变化面板。
- 同一可比系列有至少两个不同日期的有效点时，绘制可点击、可聚焦的小图；小图本身进入完整趋势，
  不再附加每行“查看趋势”文字。
- 尚未确认可比、但数值和日期可靠且单位明确一致的记录可显示独立散点，不连线、不参与派生计算。
  完整趋势页用一次图例区分“历史记录点”与“可比系列”，不能仅以不同颜色区分。
  不同单位或标本的点分图显示；有数值／来源冲突的点不因缺方法规则放宽而获得绘图资格。
- 只有一个日期或没有可绘制结果时，主表趋势摘要显示“—”，不逐行显示“记录不足”“暂不能绘制”。
  缺失原因通过该格的可访问说明及可点击／可聚焦的简短提示提供，不仅依赖鼠标悬停。
  有可靠单点时该格仍可进入完整趋势页查看该点和原始记录；主表占位不表示原始结果缺失。
- 同一展示行包含多个不可混合的可比系列时，该格提供“分组查看”入口，进入完整趋势分别展示，
  不把它们连接成一条折线或放在没有解释的同一数轴上。
- 同日多份报告全部保留；按既有规则断开折线，不平均、不任取一份。
- 日期缺失的结果保留在表内，但不伪造日期加入趋势；质量受限记录不因展示归并进入计算。
  绘制历史点、连接可比点、计算派生变化分别判断资格，不把绘图可见等同于允许计算。
- 图形使用中性色，不用红绿表达上升等于恶化或下降等于改善。
- 箭头只用于该结果相对报告参考依据的偏高／偏低；较上次增长或降低以文字及正负值表达。
- 完整趋势入口沿用现有功能，并保持当前患者、指标和有效日期筛选；提供文字数据作为图形替代。

默认关闭原为本轮评审建议；本次按用户要求实现整份规格，采用此默认值并保留开关状态。

## 8. 报告标题与医院

表格采用紧凑数值列、居中排版、轻量虚线网格；日期和医院分上下两层。每个报告列的标题顺序为：

1. 检查日期；
2. 检测医院；
3. 仅在同日同院多份报告需要区分时附简短报告编号。

检查日期本身为报告链接，不再增加每列重复的第三行“查看报告”。

医院取当前有效解析中、与该报告或对应检验结果有可靠关联的检测机构。
优先使用有明确结果级依据的机构，再使用所属报告的已确认机构；没有信息显示“医院未识别”。
不以文件名、上传者或邻近报告的医院推测。一个文档包含多个机构时，按有依据的报告单元分列；
无法区分归属时标题显示“多机构，待核对”，详情保留原文，不任取一家医院。

医院名称支持换行；特别长的名称最多显示两行，通过可点击／可聚焦的展开方式查看全称，
手机不能只能靠鼠标悬停查看。报告页始终显示完整机构名。

同日同院不同报告保留独立列；一份文档含多个检查日期时保留独立日期列，链接回同一原报告。
报告机构更正或解析版本切换后，表头同步更新。

## 9. 固定表头、分组与滚动

采用**一个共用报告表头、分组作为表内分隔行**的结构。
不继续采用每个分组各一张、各自横向滚动的表格，也不把双重纵向滚动作为固定表头的必要条件。

- 仅生成一个真实表头，视觉与辅助技术共用；不另建隐藏副本。样式加载异常时也不得出现第二套日期／医院标题。
- 浏览后续指标时，日期、医院及已开启的“变化趋势”标题固定在可见顶部，避开应用导航。
- 左右滚动时，“检验指标”首列固定；左上角同时固定，遮挡层级及背景正确。
- 所有分组使用同一列宽和横向位置，切换到后面的分组也能对应同一报告标题。
- 分组标题显示“血常规 · N 项”，替代“组可比依据”；可折叠，默认展开。
- 折叠只隐藏该分组指标行，不改变报告列或跳回水平起点；当前页面内保留展开状态。
- 每种设备只保留一个主要纵向阅读滚动面。优先使用页面纵向滚动及表头吸顶，表格仅承接横向滚动；
  具体固定及同步方式在浏览器原型中验证，不直接假设普通横向 overflow 容器下 sticky 一定生效。
  若桌面采用固定高度的表格工作区，该工作区应成为主要阅读区域，避免滚轮在两层之间来回切换；
  手机优先自然页面滚动。表头不能因筛选项多、缩放或软键盘而占满可用视口。
- 桌面和手机均避免页面级横向溢出；手机保留指标首列，剩余报告区域可横向滑动。
- 表格区域可键盘聚焦并用方向键滚动，焦点轮廓不能被固定表头遮住。
- 分组折叠、趋势显示切换、查看依据或来源返回后，维持用户阅读位置。

“标题始终可见”的验收指：用户在比较表区域浏览任意指标时，均能看到对应报告标题。
离开比较表去页面其他区域时不悬挂孤立表头。医院长名称所需的表头高度应自动参与固定布局。

## 10. 异常标记规则

### 10.1 视觉呈现

偏高显示 `11.2 ↑`，偏低显示 `2.8 ↓`；方向符号紧跟结果值，不能放到远离数值的详情中。
参考演示表格，高值数值及箭头用深红色，低值数值及箭头用深绿色；同时提供“偏高”“偏低”的可访问文本，保证黑白和色觉差异下可辨识。
不把整行或整格铺满高饱和颜色。

页内只显示一次箭头和琥珀色点线的简短图例；悬停、可访问名称与点击结果页均能说明需要确认依据，逐结果核对文字按第 6 节显示。
详情说明该次箭头来自“报告原标记”或“按本报告参考范围对照”。

### 10.2 判定与冲突

| 情况 | 主表行为 |
| --- | --- |
| 有可信的报告高／低标记，且与可用参考范围对照一致 | 显示对应箭头；详情保留原标记和范围 |
| 无报告标记，但本结果与参考范围的关联可信且可明确判定 | 高于显示 ↑，低于显示 ↓ |
| 参考范围缺失，但存在可信且与该结果正确关联的报告高／低标记 | 按报告标记显示箭头；详情说明来源 |
| 报告标记与可靠参考范围对照矛盾 | 数值使用琥珀色点线，详情并列原标记和范围；不擅自选一方 |
| 数值、单位、标记或范围有相关识别／关联冲突 | 数值使用琥珀色点线，不生成确定方向 |
| 明确位于报告范围内且无冲突 | 不显示异常标记 |
| 没有足够异常判定依据 | 不生成箭头；详情显示“暂无可用参考依据”，不能宣称正常 |
| 定性、半定量结果与报告参考结果不一致，或报告仅标注一般异常 | 显示“异常”，不强行使用上／下箭头 |
| `>…`、`<…` 等比较符结果 | 只有沿用既有边界校验可明确判断方向时才显示箭头 |

判定使用每份报告自身、正确关联的参考范围，不从其他医院、其他报告或通用网络范围补齐。
阳性不自动等同于异常；须有原报告标记或可用参考结果的支持。
同一行不同报告可有不同参考范围，分别判定；异常箭头与能否参与跨报告趋势是独立状态。
检测方法缺失不单独阻断上述异常判断，也不在没有其他问题时触发“待核对”。
人工更正后的有效结果、参考范围和原标记如出现矛盾，按冲突处理，不沿用旧箭头。

## 11. 状态、兼容与实现边界

- 所有筛选、详情、来源与趋势操作保持当前患者；无资格成员不能读取结果。
- 人工修订、重解析、切回旧版本、来源删除后，重新构建表格、表头、异常及趋势。
- 未归类和低置信度结果继续可见，不因精简界面而丢失；直接影响本格结果的原因使用琥珀色点线标记，其他说明按第 6 节放在核对页。
- 页面无数据、筛选无结果、日期错误、日期未知、机构未知、同格多值分别有明确状态。
- 保留原报告链接和字段来源，展示归并不修改原始数据、有效修订链或现有导出事实。
- 旧比较页地址与单 `category` 查询兼容；多选采用可重复查询参数或等价的明确序列格式，
  不把多个分组拼成无法识别的单个字符串。
- 首期按现有数据读模型实现；不以数据库迁移作为既定前提。表头机构应批量读取，
  避免每个单元格重复访问机构信息。
- 大量报告仍全部可访问，不为提升速度静默截断。性能基准见下节；若需要分页或虚拟化，
  应先验证固定表头、完整数据访问及键盘行为，再决定实现方式。

| LC-08 | 高值、低值、范围内、缺范围但报告有标记 | 箭头及来源符合规则，正常／未知不混淆 |
| LC-08 | 方法为空但本报告结果、参考范围或标记可信 | 异常判断正常执行，不因方法为空隐藏箭头或显示待核对 |
| LC-08 | 边界值、单边范围、比较符、定性及标记冲突 | 沿用边界包含规则；冲突待核对，不编造方向 |
| 通用 | 切换患者、只读成员、撤权、删除来源、重新解析和人工修订 | 无跨患者或失效数据泄露，结果与派生状态同步更新 |

实施验收还需用不少于 100 个指标行、50 个报告列的合成数据检查滚动、展开和响应。
建议初始目标：约定的本地桌面 Chromium 环境下，筛选至结果可操作不超过 2 秒；
依据页访问复用现有性能基准，不把未经测量的 200 毫秒设为新功能硬门槛。
记录浏览器、硬件、数据量和实际测量值，不把目标当作通过证据；量化门槛在基线测量后确定。
正式性能结论应与同环境当前页面基准对照，并说明移动端测试结果。

核心验收以“不误合并、不丢结果、不误连线、任意行可辨认日期医院、异常标记有来源”为准。
实际用户样例可在经授权的本地环境复核；包含个人资料的报告及验证证据不得直接放入公共测试夹具。

## 13. 实施顺序与评审结论

建议作为一个完整优化包实施，分四步验证：

1. 建立展示行、历史绘图、可比连线及派生计算的独立资格判断；落实按指标接受方法缺失的规则机制，完成边界回归。
2. 完成检验指标搜索、多选分组、报告机构表头、共用表格与固定滚动布局。
3. 完成紧凑结果格、单位去重、数值直达现有依据页、异常标记与按需趋势摘要。
4. 完成桌面／手机／键盘验收、数据权限回归及文档状态更新后，再进入交付流程。

不建议仅删除详情文字并把所有同名结果直接合并：这样不能解决指标身份歧义，也可能使
原先分开的不可比记录被连成趋势。推荐采用本文已明确的展示归并、严格计算和分层详情方案。

归并边界、结果点击入口、趋势命名、分组默认行为及异常冲突规则均已给出推荐决策，
实际报告拆行原因仅在取得对应报告后核实，不以合成回归替代真实样例诊断。
用户此前确认取消逐格详情和第 5.3 节方法原则，随后于 2026-09-14 要求实现本规格；
本次实施覆盖八项完整要求。功能实现不包含版本字段手工变更或生产部署，原方案合并本身不构成功能交付证据。

## 14. 本轮产品评审记录

本轮为基于八项反馈、现有代码及方案的产品设计评审，未进行实际用户可用性测试。
八项目标均成立，主要问题来自上一版方案的实现方式和过度扩展，而非用户的原始诉求。

| 问题及级别 | 评审意见 | 本版处理 |
| --- | --- | --- |
| 逐格“详情”及常驻操作，必须调整 | 数字表又变成操作列表，违背减少无用信息的目标 | 删除逐格文字／图标，点击数值进入已有依据页 |
| 新桌面侧栏及手机详情面板，建议削减 | 已有核对页可用，新面板增加维护、焦点及返回状态复杂度 | 本期复用已有页面，取消新增面板 |
| 每格重复单位，建议优化 | 同行单位一致时重复显示降低阅读密度 | 确认一致才集中至单位列；混合及未知单位逐格保留 |
| 趋势列常驻与逐行无法绘图说明，建议调整 | 占用报告宽度，且用户只是询问术语，并未要求常驻图表 | 更名，建议默认关闭；页面级开关显示，空图用短占位 |
| 同名展示与指标身份须分离（2026-09-21 更新） | 标本和候选状态不能在集中展示后丢失 | 同名集中展示，逐结果标本及核对状态可见；计数与百分比分行，计算资格独立 |
| 缺方法则所有趋势都禁止，已确认调整 | 全局缺方法门槛过于生硬，缺失也不能推定方法一致 | 本期按第 5.3 节拆分展示、绘点和计算资格，计算按指标审核规则，不统一放开 |
| 为吸顶强制增加表格纵向滚动，建议调整 | 手机嵌套滚动和小视口会增加阅读负担 | 验收单一主要纵向滚动，先验证吸顶原型 |
| 对原始名称逐条搜索，必须补齐 | 搜索别名可能让其他报告同指标值消失，破坏纵向比较 | 先找指标身份，再取日期／分组范围内的整行历史 |
| 异常一律使用箭头，需要边界 | 定性异常无上下方向；参考范围与原标记可能冲突 | 有明确方向才给箭头，否则显示“异常”或使用琥珀色点线 |
| 取消最后分组自动选择全部，建议澄清 | 自动重新勾选容易违背取消意图 | 不选表示不限，不自动勾回；面板明确说明 |
| 直接设 200 毫秒详情性能门槛，依据不足 | 缺少环境和现有测量，且新增面板已取消 | 按真实基准测量后确定量化门槛 |

建议后续再评估、未纳入本期强制范围的能力：

- **仅看异常指标**：适合行很多时定位；若增加，应保留所选异常指标整行的正常历史供对照，
  并明确“任一次异常”还是“最新一次异常”，不能把两种规则混用。
- **快速定位最新报告**：日期从早到晚便于阅读变化，但历史列多时最新列可能不可见。
  可考虑一次页面级“定位最新”操作，优先于静默截断历史或擅自改成倒序。
- **报告选择**：长期积累后，多选报告可减少横向宽度；这比一开始就引入复杂分页更贴近比较任务，
  但需要另行明确选择上限、默认范围及筛选关系。

最终优先级为：先保证指标和数值正确对齐，再减少重复内容、固定日期医院，最后优化趋势及其他辅助操作。
