# 稳定病灶、范围侧别与选定输出

本规格定义稳定病灶关联、范围侧别、病灶趋势与选定输出，细化
[临床领域规格](2026-09-08-clinical-followup.md)第 3 节。功能已实现并验证，见
[病灶验证](../archive/verification/batch-three-lesion-relations.md)；真实质量单独判断。
固定真实集阳性关系为 0，`retention_gate_passed=false` 与 `RETENTION_REVIEW_REQUIRED`
保留，不表示临床质量通过。当前产品范围见[产品状态](../product/current-state.md)。

## 1. 用户流程与身份

患者的病灶页面汇总报告内观察、待核对提议及已确认关联。每份报告的局部实体保持原有
`entity_key`；患者长期病灶使用独立 UUID。两份报告出现相同实体编号不构成关联依据。

用户主动生成提议后，可同时打开两端原件，查看部位、侧别、日期、检查方法和对比引用
依据；可确认、拒绝、暂缓或手动选择观察。确认建立稳定标识或连接已有标识，后续可命名、
改派、拆分、解除关联和撤销操作。GET 页面不生成提议，重复生成保留已有拒绝和暂缓决定。
所有决定追加真实作者、前后状态及来源版本，不覆盖自动字段或旧修订。

自动提议仅使用同患者、不同报告的明确字段证据。相似尺寸或同一器官不能证明病灶身份；
相反侧、不同部位、同报告多灶、多个候选、未知方法/日期、不确定比较分别保留拒绝条件或
待核对限制。提议始终为 `PENDING`，不会自动确认字段、关联或医学结论。

## 2. 侧别作用范围

| 表示 | 含义 | 下游使用 |
| --- | --- | --- |
| `lesion.laterality` + `WHOLE_ENTITY` | 原文明确限定整个部位实体 | 当前父部位和侧别均确认且来源有效时，可作为整实体侧别依据 |
| `lesion.scoped_laterality` + `NAMED_MEMBERS_ONLY` | 原文只限定列明的成员 | 逐成员显示，不推广为整组侧别，不作为整组匹配依据 |
| 旧标量 + `UNKNOWN_SCOPE` | 旧值仍可读，但没有完整作用范围证明 | 保留原值、修订和限制，不能自动升级为整实体侧别 |

成员保留名称、侧别、原表达和自己的来源区间，并绑定同报告同实体的实际父部位字段。
成员名称必须由成员自身的原区间或显式人工页转录证明；父原文其他位置出现同词不足以
通过。核对同时检查父部位当前修订、成员绑定和完整来源；父被排除、撤销、替换、重新
解析或删除后，成员不可继续用于匹配、趋势或输出。恢复父记录不会复活旧确认，须重新核对。

旧字段、金标准和评分结果不回写。旧标量任务中的真实缺失保留，范围字段单独捕获；
不把新字段别名映射到旧 key，也不以旧标量的类别匹配证明作用范围正确。固定真实集中有
一项旧整组标量不再产生，这是接受的语义取舍；原保留门禁仍为 `RETENTION_REVIEW_REQUIRED`。
完整分母与来源变化见[逐项保留结果](../archive/verification/batch-three-lesion-relations.md)。

## 3. 趋势与可比性

只有来源有效、字段已核对且关联已确认的观察可用于稳定病灶趋势。尺寸保持最多三维的
原顺序、轴、原值、单位、约数、范围和时间角色；明确厘米可换算毫米，保留转换依据。
不能用三维最大数冒充报告明示长径，也不能把报告引用的历史值重复计成本次测量。

尺寸和 SUVmax 分别展示。只有日期、方法、轴、单位和时间角色满足可比条件时才连接点或
计算精确差值；未知、冲突、约数、区间、不可用的中间观察及同日歧义保留具体限制。
可显示的单点不因此获得连线资格。报告最大病灶视图只使用原文明确的 `REPORT_MAXIMUM`，
不对不完整候选集合求最大值，不计算 RECIST 或自动疗效等级。

## 4. 来源、权限和并发

关系绑定实际报告、文档、字段及其完整来源和修订。写入按既有患者、批次、文档、领域行
锁序重新检查当前权限和版本；跨患者、只读角色、过期提议及冲突提交均被拒绝。
撤销只追加新的有效操作，不能跨越来源变化恢复旧确认。

病灶、提议、操作历史及相关字段核对页面在构建数据前捕获来源和历史，渲染后重新查询并
检查实时权限。期间来源或历史作者改变时丢弃已准备的旧正文，返回受保护的失败响应。
原件清除保留必要的不透明历史身份；患者删除覆盖整个关系图。历史快照随数据量增长，
尚无生产规模性能结论。

## 5. 搜索、速查、导出与分享

搜索可显示已核对观察关联。用户明确选择稳定病灶、报告及字段后，速查、CSV/JSON/ZIP
和分享仅投影选中且有效的观察及测量，至少保留该观察的已选部位字段。普通影像章节选择
不等于选择病灶关系；选一个病灶不自动携带另一份报告、未选字段或完整原件。

病灶关系自 portable `1.6` 引入 `lesions`、`lesion_observations`、
`lesion_measurements` 及对应 CSV 表。当前包装版本为 `1.8`，与云影像、癌种及分子等
领域数组共同保存。旧格式读取时，缺失的病灶表补为空，不改写原文件；
`1.0` 至 `1.5` 不可携带病灶关系图。字段模式版本独立校验，
混合输出仍遵守每个领域的来源绑定和分享边界。

公开内容只包含选定图，完整关联历史、作者活性、两端来源与修订进入私有指纹。选定输出
不会因隐藏了某字段而忽略它的依赖变化；预览、下载流和分享释放正文前重新核验，旧快照
失效须重新生成。细选删除比较上下文后不得用剩余点重新跨越原来的不可比间隔。

沿用主线云影像默认省略外部访问信息的规则。类型化值中需要保留的成员范围和数值显示
从有效结构重新构建；省略标志仅在当前对象真实带有省略标记时有效，不能从父对象继承
来绕过枚举、长度、来源或关系图校验。即使仅隐藏 URL 改变而显示文字相同，旧输出仍失效。

## 6. 验收边界

合成行为验证覆盖操作、来源生命周期、跨患者、并发、浏览器和选定输出。真实评测使用
预先冻结的关系、七字段、量化和摘录任务，分别公布分母及限制；零阳性关系金标的准确率
保持 `null`。三次实际运行、原失败与全部旧评分保留，不为文档整理另行预测或重评分。

功能验证、真实质量、源码发布和[生产放行](../verification/release-gate.md)
分别记录。病理、分子、癌种排序及云影像的当前合同见各领域规格。
