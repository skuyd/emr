# 日常记录需求规格

需求确认日期：2026-10-01。

用户已确认本轮需求及交互原型，本文件直接覆盖原有需求，作为开发和验收依据。实现与本地验证见[实施计划](../plans/2026-10-01-daily-self-records.md)及[本轮验证记录](../verification/daily-self-records.md)；当前交付状态以[文档登记表](../document-registry.json)为准，发布版本以实际发布清单为准。

交互依据：[日常记录原型](../../prototype-gallery/daily-records-preview.html)。原型使用示例数据，仅用于确认页面和操作流程，不代表数据库、权限、迁移或正式应用已经实现。

原 v1.10.0 的交付事实保留在[历史验证记录](../verification/batch-five-daily-records.md)及[版本清单](../releases/v1.10.0.md)。其中时区、修订历史和撤销等行为不再作为本轮开发要求，历史测试通过也不代表本轮需求已通过验收。

## 1. 目标与范围

用户能够快速记录体重、体温、身体感受及 ECOG 评分，直观看到已经记录的内容，并在录入错误时直接更正或确认删除。录入与已有记录分区展示，避免把已保存的数据误认为当前正在填写的内容。

本次确认的范围：

1. 移除时区、夏令时重复时刻选择，以及“补充测量方式或备注”相关字段和提示。
2. 按用户填写的日期、时间保存和展示；新增时默认当前设备日期、时间。
3. 提供日历和列表两种浏览方式，默认日历。
4. 记录类型有明确选中状态，新增 ECOG 评分类型。
5. 保存后留在添加页面，支持连续添加；用户点击“返回列表”才回到浏览页。
6. 添加页面侧边展示所选日期、所选类型的已有记录。
7. 提供更正、删除入口；更正直接更新记录，不保存修改历史。
8. 删除前确认；取消“撤销删除”功能。

日内血糖仍属独立功能。本次不新增趋势分析、评分推算、诊断或治疗建议，也不新增历史版本管理、回收站或批量删除。

## 2. 记录浏览页面

### 2.1 共用操作

- 页面名称为“日常记录”，提供“记一条”入口。
- 首次进入默认显示当前设备月份的日历，并选中今天。
- 提供“日历 / 列表”切换和类型筛选，筛选项为全部类型、体重、体温、症状、ECOG 评分。
- 月份两侧的“上个月 / 下个月”按钮必须显示可辨认的箭头，不得出现空白按钮；同时提供“今天”按钮。
- 两种视图使用同一月份和类型筛选。切换视图不改变筛选范围。
- 从添加页面返回时保留本次使用的日历或列表模式。“返回列表”表示回到记录浏览页，不强制切换为列表模式。

### 2.2 日历视图

- 按周一至周日显示月历；今天、当前选中日期和其他月份日期有可区分的样式。
- 有记录的日期显示类型与数量摘要，窄屏可缩为记录数量；不能只靠颜色表达是否有记录。
- 点击日期后，在独立区域显示当天符合类型筛选的记录，包含类型、结果、单位，以及实际填写的时间。ECOG 只显示日期和评分，不显示虚构时间。
- 同一天可有多条同类型记录，分别显示，不按日期覆盖或合并。
- 没有记录时明确显示空态；月份和每日数量与筛选后的实际记录一致。

### 2.3 列表视图

- 展示所选月份内符合筛选的记录，按日期从新到旧分组；有时间的同日记录按填写时间从晚到早排列。
- ECOG 归属填写日期，不参与具体时刻比较，不补成 00:00。同刻多条记录均保留，不暗示未提供的先后顺序。
- 每条记录可展开查看完整日期、时间和内容，并进入“更正记录”。
- 当月没有符合条件的记录时显示空态，不展示示例数据或上一筛选条件的残留结果。

## 3. 添加记录与时间规则

### 3.1 字段

| 类型 | 必填内容 | 字段说明 | 时间精度 |
| --- | --- | --- | --- |
| 体重 | 测量时间、数值、单位 | kg、g、lb，默认 kg | 日期和时间，精确到分钟 |
| 体温 | 测量时间、数值、单位 | °C、°F，默认 °C | 日期和时间，精确到分钟 |
| 症状 | 发生时间、症状名称 | 自述程度，可留空 | 日期和时间，精确到分钟 |
| ECOG 评分 | 日期、评分等级 | 0–5 分单选，不增加其他录入字段 | 仅日期 |

“自述程度”保留为症状本身的描述，不是通用备注；不再提供测量方式、补充备注、时区、UTC 偏移或夏令时选择区域。

### 3.2 时间语义

- 打开新增表单时，体重、体温、症状默认当前设备日期和时间，ECOG 默认当前设备日期，均允许修改或补记。
- 用户修改后，以最终填写内容为准，不在保存时用服务器时间覆盖；表单停留期间不持续刷新并覆盖用户输入。
- 记录时间不要求录入或选择时区，不按浏览设备、服务器时区或 UTC 换算。换一台设备查看时，仍显示当时填写的日期和时间。
- 不进行夏令时重复时刻区分，也不因时区的夏令时规则拒绝用户填写的合法日期和时间。
- 必填日期、时间缺失或格式无效时提示补充；ECOG 不要求时分，其他类型不能把缺失时间自动补成午夜。
- 更正已有记录时先回填该记录保存的日期和时间，不用当前设备时间替换。

### 3.3 类型选择与校验

- 新打开添加页面默认选择体重；四个类型按钮使用相同层级，选中项通过背景、边框和勾选标记明确变化，具备可读取的选中状态。
- 切换类型只显示该类型需要的字段，并立即更新已有记录区域。当前页面内切回类型时保留尚未提交的输入，避免误切换造成丢失。
- 体重和体温要求可解析的有限数值及合法单位；症状名称去除首尾空白后不能为空。沿用现有数值表示能力，不按人体参考范围自动修正数值。
- ECOG 必须主动选定一个整数等级，不能预选正常等级；0 分是有效结果，不得按空值处理。
- 校验或保存失败时保留输入，显示具体错误，不提示保存成功，不增加记录或清空表单。

## 4. ECOG 评分

类型按钮名称为“ECOG评分”。录入内容只有日期和评分等级。每个等级同时显示分数和简短说明，用户选择一项后保存。

### ECOG Performance Status Scale

| 等级 | 页面说明 |
| --- | --- |
| 0 分 | 活动正常，不受限制。 |
| 1 分 | 剧烈活动受限；可行走，能做轻体力或坐位工作。 |
| 2 分 | 能完全自理，但不能工作；清醒时间中超过一半可离床活动。 |
| 3 分 | 仅能部分自理；清醒时间中超过一半卧床或坐椅。 |
| 4 分 | 完全不能自理，整日卧床或坐椅。 |
| 5 分 | 死亡。 |

以上为 [ECOG-ACRIN 官方分级](https://ecog-acrin.org/resources/ecog-performance-status/)的中文简述，核对日期为 2026-10-01。量表由 Eastern Cooperative Oncology Group 制定，1982 年发表：Oken MM 等，*Toxicity and response criteria of the Eastern Cooperative Oncology Group*，Am J Clin Oncol. 1982;5(6):649–655，PMID: 7165009。页面保留分级依据链接。

系统记录用户所选等级，不通过症状、体重等自动计算评分，也不由评分自动给出诊疗结论。日历、列表、已有记录区域及更正表单统一使用同一等级含义。

## 5. 保存与连续添加

1. 用户选择类型并填写内容，点击“保存记录”。
2. 保存成功后仍在添加页面，提示已保存的类型、结果及日期/时间，明确“可继续添加下一条”。
3. 保留当前类型及单位，清空刚保存的数值、症状/自述程度或 ECOG 选择，避免再次点击产生相同记录。
4. 下一条记录的日期/时间更新为保存完成时的当前设备日期/时间，仍可手动修改。
5. 已有记录区域按更新后的表单日期刷新。若刚保存的是补记日期，成功提示仍明确显示补记日期；不能将补记记录混入今天的记录。
6. 用户可继续填写同一类型或切换类型添加。只有点击“返回列表”才退出添加页面；返回操作不自动保存尚未提交的内容。
7. 返回浏览页后可看到已保存记录；定位最近保存记录所在月份和日期，类型筛选恢复为全部类型，保留日历/列表模式。

同一次提交的重复点击或网络重试不得产生重复记录；用户明确发起的下一次记录仍可独立保存。已有同日、同类型记录是核对提示，不是“一天只能录一次”的限制。

## 6. 添加页面的已有记录区域

### 6.1 布局与内容

- 桌面采用左侧录入、右侧已有记录的布局，两个区域独立成卡并顶部对齐。
- 标题为“当天已记录 · 当前类型”，明确显示所查日期、今天标识（适用时）和记录条数。
- 窄屏在完整录入表单及其操作按钮之后显示已有记录，不能插在类型、日期、输入值或保存按钮之间。
- 区域只展示当前患者、表单所选日期、当前类型的有效记录；“当天”指表单日期，默认是今天。
- 有时间的记录显示时间和内容；症状包含已填写的自述程度；ECOG 显示评分，不补时间。
- 每条记录提供“更正”“删除”入口；正在更正和刚刚保存的记录有文字标识。

### 6.2 刷新规则

- 切换类型、修改日期、保存、更正、删除后同步更新条目和计数，无需用户手动刷新页面。
- 不受浏览页此前的类型筛选影响，例如浏览页筛选体重后，在添加页选择体温仍须显示该日体温记录。
- 无记录时显示“当天还没有××记录”；尚未填写日期时提示先选择日期。
- 正式应用读取失败时显示读取失败及重试提示，不将失败伪装成“没有记录”，以免误导用户重复录入。

## 7. 更正记录

- 可从浏览记录的“更正记录”或添加页已有记录的“更正”进入；都使用同一表单。
- 回填当前有效内容，标题改为“更正××记录”，说明保存后直接更新这条记录；按钮为“保存更正”“取消更正”，顶部仍保留“返回列表”。
- 更正时保持原记录类型，允许修改该类型的日期/时间、数值、单位、症状内容或评分；不通过更正把一条记录变成其他类型。
- 保存更正直接更新同一条记录，不新增副本，不保存更正前后内容或修改历史，不提供历史对比、恢复旧值或撤销更正功能。
- “取消更正”仅放弃本次尚未保存的编辑，已有记录保持原值。
- 从添加页侧边进入更正时，临时保留尚未提交的新记录；保存或取消更正后回到添加状态并恢复该输入及日期/时间，继续添加，不自动返回浏览页。
- 从浏览页进入更正且没有待恢复输入时，保存或取消后留在表单，回到可添加状态。
- 更正后按原记录类型和更新后的日期同步已有记录、日历、列表及计数，不在原日期残留旧副本。

临时保留的未提交输入只用于当前页面衔接，不属于修改历史，也不新增跨设备或长期草稿功能。

## 8. 删除记录

1. 点击已有记录上的“删除”时先显示该条记录的确认区域，不立即删除。
2. 确认区域明确询问“确认删除这条××记录？”，显示日期、实际存在的时间、结果及单位/自述程度，避免删错对象。
3. 提供“取消”和“确认删除”；确认删除使用清楚的危险操作样式，不能只凭颜色区分。
4. 点击“取消”关闭确认，记录和当前未提交输入均保持不变。
5. 点击“确认删除”且操作成功后移除记录，同步更新计数和浏览结果，仅提示“已删除记录”。仍停留当前页面，保留正在填写的新记录。
6. 若删除的是正在更正的记录，退出其更正状态，恢复此前临时保留的新记录输入；没有该输入时回到可添加状态。
7. 删除失败时保留记录并提示错误；没有确认删除的操作不得修改数据。

不显示“撤销删除”按钮、倒计时、可恢复占位条目或回收站；不保留用于撤销的记录缓存或恢复接口。切换类型、返回浏览、刷新或重新进入后，已删除记录不得重新出现。删除确认取消后、切换类型或日期后，不能继续确认先前已失效的删除对象。

## 9. 既有数据与关联功能边界

本次调整作用于日常记录，不改变其他模块的记录方式或修订规则。既有患者归属、家庭成员权限及选定输出边界继续生效：只读成员不能新增、更正或删除；跨患者请求和失效权限必须拒绝。

- 记录保存当前有效值与用户填写的日期/时间。后台创建、更新时间可用于系统管理，但不能冒充测量或发生时间。
- 更正直接更新有效记录；不以隐藏原始副本、前后值事件或审计载荷继续保存本次业务修改历史。权限、安全事件记录与内容修改历史区分，不能据此恢复已取消的功能。
- 并发写入和请求重试仍须避免重复新增、覆盖他人已保存结果或复活已删除记录；这不要求保留业务修改历史。
- 现有有效记录应继续可读、可更正、可删除。已有记录保留的用户原始当地日期/时间作为兼容依据，不随当前设备时区漂移；数据迁移不得通过批量换算改变用户原先填写的日期或时间。
- 移除录入字段不等于授权批量清空旧库。旧时区、备注和既存修订数据的物理清理不在本轮交互需求范围内；不得因表单简化删除有效记录。
- 既有数值和单位保留用户输入含义；必要的换算不覆盖原值，也不新增医学范围截断。
- 既有速查、导出和分享继续遵守明确选定的记录范围；新记录类型与日期精度接入现有读取路径，不伪造 ECOG 时间或要求用户补填时区。更正、删除及权限变化后的派生结果失效规则继续生效，不能继续展示已失效内容。

本文件规定用户行为和数据语义，不指定数据库字段布局、旧字段移除批次或新的结构化导出版本号。实施时根据实际依赖制定兼容改造与验证，不将原型的内存操作当作正式数据处理方案。

## 10. 验收标准

下列标准适用于正式应用；原型仅提供交互参考，不作为正式功能通过的证据。

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| DR-01 | 检查所有记录类型的新增、更正与浏览页面 | 不出现时区、UTC 偏移、夏令时重复时刻选择、测量方式或补充备注入口 |
| DR-02 | 打开新增表单并手动修改时间 | 默认设备当前时间；保存、重开及另一时区设备查看均保留用户填写值 |
| DR-03 | 填写合法但在某时区存在夏令时歧义的时间 | 无需偏移选择，不按夏令时规则阻止保存或改写时间 |
| DR-04 | 首次浏览、切换月份及点击今天 | 默认日历与今天，前后月份箭头可见、可操作，跨年正确 |
| DR-05 | 日历与列表切换、类型筛选及空月份 | 两种视图结果和数量一致，空态正确，同日多条记录均可查到 |
| DR-06 | 切换四种记录类型并切回 | 选中状态明显；只显示对应字段，保留未提交输入；更正时不能改类型 |
| DR-07 | 新增 ECOG，分别测试 0 分、5 分及未选等级 | 只需日期和等级；0、5 均可保存，无预选等级，不补时间；未选等级不能提交 |
| DR-08 | 缺失时间、空症状、无效数值或非法 ECOG 等级 | 明确校验错误，无记录写入，不丢失已填内容 |
| DR-09 | 连续保存两条记录 | 每次成功后留在添加页，保留类型/单位、清空已保存内容、更新时间；两条记录独立存在 |
| DR-10 | 补记过去日期后继续添加 | 成功提示显示补记日期，下一条默认当前设备时间；侧边日期与所列记录一致 |
| DR-11 | 点击返回列表 | 返回此前日历/列表模式，已保存结果可见，未提交内容不被自动保存 |
| DR-12 | 添加页切换类型、日期及带入浏览筛选 | 侧边仅显示当前患者、所选日期和类型，不受浏览筛选误裁剪；日期缺失、空态正确 |
| DR-13 | 同日同类型再次记录与同次请求重试 | 真正的第二次录入允许保存；重复点击/重试不重复创建同一次记录 |
| DR-14 | 已有记录读取或提交失败 | 明确显示失败，读取失败不冒充无记录；保存失败不清空输入或显示成功 |
| DR-15 | 从侧边更正后保存、取消，或更正日期 | 更新原记录且不新增；取消不改原值；原新记录输入恢复；新旧日期条目和计数正确 |
| DR-16 | 完成更正后检查内容持久化和页面 | 只保留当前有效内容，不新增修改历史、原始副本、前后值；无历史恢复入口 |
| DR-17 | 点击删除、取消，再确认删除 | 第一次点击只展示对象摘要与确认；取消无影响；确认成功才移除并提示，未提交输入保留 |
| DR-18 | 删除正在更正的记录、取消后换类型/日期 | 正确退出更正并恢复新输入；失效确认不能误删其他记录 |
| DR-19 | 删除后切换视图、刷新或重开页面 | 记录不再出现；无撤销入口、恢复占位、倒计时或可调用的撤销删除能力 |
| DR-20 | 桌面、320px/360px 窄屏及键盘操作 | 桌面侧边、窄屏表单之后显示已有记录；无横向溢出，按钮和焦点可辨认，类型选择与删除确认可用键盘完成 |
| DR-21 | 迁移既有记录、跨患者与只读成员操作 | 有效记录及填写时间不丢失、不漂移，权限边界不变 |
| DR-22 | 关联输出、更正/删除与并发写入 | 选定范围和日期精度正确，失效内容不继续输出，并发或旧页面不复活已删记录、不静默覆盖较新结果 |

## 11. 验证与交付要求

开发时围绕上述编号补充必要的输入、服务、持久化和真实浏览器验证，重点覆盖 0 分、仅日期、连续添加、侧边核对、更正保留未提交输入和删除确认。涉及既有数据、权限、并发及选定输出的改造须执行相应迁移与回归检查。
