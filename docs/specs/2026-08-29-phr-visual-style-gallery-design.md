# 肿瘤个人病案视觉风格画廊设计

## 目标

为《产品方案 v2.0》第一阶段提供四套差异明显、可直接比较的 HTML 视觉方向。每套方向都覆盖首页/上传、病案浏览和原件详情三个核心页面，并使用相同的模拟病案内容，确保比较的是设计而不是内容差异。

## 用户与核心任务

- 主要用户：帮助肿瘤患者整理资料、陪同就诊的家属照护者。
- 首要任务：无需培训完成图片/PDF 批量上传。
- 留存任务：在 30 秒内搜索并打开一份目标资料或原件。
- 信任要求：原件始终可见；自动识别只作为查找辅助；界面不输出诊断、疗效或治疗建议。

## 共同信息架构

四套方案使用同一信息架构：

1. 首页/上传：患者身份、上传入口、处理进度、最近资料。
2. 病案：关键词搜索、简单筛选、按日期浏览。
3. 详情：原件预览、基本信息、自动识别字段、来源定位和错误反馈。

共同状态固定为“处理中、已整理、仅原件、处理失败”。详情页固定显示“自动识别结果可能不准确，请以原始报告为准”。

## 四个视觉方向

### A. 暖笺 · 家庭档案

- 暖米白、赤陶和鼠尾草绿；宋体标题与柔和圆角。
- 顶部导航加宽幅上传主行动，最近资料采用杂志式卡片。
- 目标：降低医疗资料带来的压力，强调“替家人收好每一份原件”。

### B. 明晰 · 专业工具

- 高对比白、钴蓝和青色；系统无衬线字体与紧凑数据布局。
- 左侧固定导航、全局搜索、状态概览和表格式病案。
- 目标：最快完成查找，适合资料量大、频繁使用的照护者。

### C. 经纬 · 时间轨迹

- 深海军蓝、薄荷青和酸橙点缀；几何字体和显著日期刻度。
- 以纵向时间轴为主体，上传与检索成为时间线两端的固定入口。
- 目标：让跨医院、跨月份的资料先按时间建立清晰秩序。

### D. 随身 · 轻陪伴

- 雾紫、珊瑚橙和柔白；圆润字体与移动端卡片语言。
- 桌面呈现为聚焦式单列工作区，底部导航、渐进式任务卡和大触控目标。
- 目标：兼顾中老年患者与手机使用场景，把一次只做一件事贯彻到底。

## 比较标准

- 自明性：首次用户是否立即知道下一步。
- 查找效率：搜索入口与原件打开动作是否足够显眼。
- 信任：原件保存状态、自动识别边界和隐私提示是否清楚。
- 可读性：中文字号、对比度、触控目标和信息密度是否合适。
- 延展性：方向能否支撑后续速查、趋势和家庭协作，而不提前暴露空功能。

## 交付与验收

- 一个比较首页，可预览、全屏打开并记录本地选择。
- 四个独立 HTML 原型，每个均可在首页、病案、详情之间切换。
- 不依赖外部字体、图片、框架或网络服务。
- 视口宽度 390px 与 1440px 下内容不横向溢出。
- 键盘可访问主要导航与按钮，焦点状态可见。
- 所有数据均为明确的模拟数据，不包含真实患者材料。
