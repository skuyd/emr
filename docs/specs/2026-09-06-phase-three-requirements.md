# 第三阶段需求范围：就诊速查、资料导出与回收站

本期功能范围已于 2026-09-06 经用户逐项确认。书面规格及第 5 节验收口径提交审阅后，
用户要求合入 `main`；本规格据此定稿，登记为 `active / planned`，作为第三阶段需求基线。
“第三阶段”是产品阶段，发布版本尚未确定，不能据需求确认宣称功能已交付或验证。

## 1. 本轮确认记录与依据

| 事项 | 用户确认的安排 |
| --- | --- |
| 事实纳入 | 系统提取候选，用户对照原件核对后纳入速查卡；每条保留来源和页码 |
| 事实深度 | 整理报告明确记载的诊断、分期、治疗名称及时间，摘录影像与病理结论；保留限定表达、缺失及冲突 |
| 速查卡 | 姓名或昵称、可选基本信息、已核对事实、治疗时间线、重点检验、影像病理摘录及来源；先采用 A4 一页正文与可选明细附页 |

## 2. 目标与已有基础

目标：用户能在就诊前从自己的资料中核对关键事实，生成可追溯的一页速查卡，选择并
导出需要携带的资料，并在误删后恢复仍处于保留期内的文档。

本期沿用一个账号对应一位患者的使用范围，主流程为：

```text
上传与整理 → 事实候选 → 原件核对 → 选择速查内容 → 预览 → PDF / 文件导出
                         ↓
               修订、重解析和来源状态校验

正常资料 → 回收站（30 天）→ 恢复为正常资料
                  ↓
             到期或主动彻底删除 → 不可恢复的删除流程
```

本规格最后核对的主分支代码基线为 `5620c54`，以下只说明实现基础：

| 领域 | 已有基础 | 本期增量 |
| --- | --- | --- |
| 原件与证据 | 文档、页面、OCR、解析版本及字段来源 | 新事实候选、核对状态与来源连续性 |
| 文档摘要 | 类型、日期和机构等文档元数据 | 面向患者的就诊速查卡及固定内容快照 |
| 检验 | 有效结果、修订、质量限制与可比性规则 | 速查卡和结构化导出复用同一有效结果口径 |
| 文件查看 | 归属校验、受保护的原件查看与预览 | 用户主动下载、结构化文件和 ZIP 打包 |
| 删除 | 删除后停止访问并调度永久清理 | 新增可恢复的回收站状态，与永久清理分开 |

代码依据：[来源及文档元数据](../../apps/processing/models.py)、
[检验有效结果](../../apps/labs/readmodels.py)、[检验修订](../../apps/labs/revisions.py)、
[原件访问](../../apps/documents/views/originals.py)、[文档删除](../../apps/documents/deletion.py)、
[账号删除](../../apps/accounts/deletion.py)。现有 `DocumentSummary` 是文档元数据，
不能据其名称视为就诊摘要已经实现。

## 3. 本期功能需求

### P3-01 事实候选与原文摘录

- 从现有支持格式的资料中提取候选，范围包括报告明确记载的诊断、分期、治疗名称和
  时间，以及影像检查结论、病理诊断等关键原文摘录。
- 每条候选保留原文、来源文档、页码、解析版本和可用的区域定位；没有精确区域时
  明确使用页面定位，不能生成不存在的坐标。
- 诊断与分期分别保留记录日期、医院和原始表达。同一患者在不同日期或报告中的记载
  分别展示，不能自动合并为一个“当前诊断”或自行判定哪一份正确。
- 治疗时间线仅采用报告明确记载的手术、药物治疗、放疗名称及时间。日期只有年月或
  无法确定时保留其精度，不补造具体日期，也不根据时间间隔推断周期或治疗持续状态。
- 影像与病理摘录保留上下文中影响含义的“考虑”“可能”“未见”等限定表达。缺失、
  相互矛盾或不能确定的内容显式标记，不能通过补写结论消除不确定性。
- 自动抽取失败时保留原件及明确状态；用户可从原件补充摘录并绑定来源，记录为人工
  补录。核对转录是否忠实于原件，不等于判断报告本身的医学结论是否正确。

### P3-02 核对、修订与生效

- 为候选提供原件对照、确认、更正、暂不处理及排除入口。只有已核对且来源仍有效的
  事实和摘录可进入速查卡与事实类结构化导出。
- 核对范围限定为用户准备纳入的事实；未完成核对不阻止原有归档、搜索和查看原件。
  检验结果沿用第二阶段规则，不新增全量检验逐行确认的前置步骤。
- 人工更正保留作者、时间、前后内容、来源及使用的版本；允许撤销确认或修订。
  自动候选与人工内容分别保存，新解析不能静默覆盖人工修订。
- 来源、事实内容或含义发生变化时，旧确认不得自动套用于新结果，相关条目回到待核对
  状态。单纯重新执行解析不能抹去仍有效的人工记录。
- 来源进入回收站、永久删除或失去访问资格后，条目不能继续作为可用事实纳入摘要。
  恢复原件后，仅在来源与内容版本仍匹配时恢复原确认状态。

### P3-03 就诊速查卡

默认内容为以下六部分，用户可在生成前选择、调整和预览：

| 部分 | 内容与边界 |
| --- | --- |
| 患者信息 | 姓名或昵称；其他基本信息由用户选填并决定是否展示，缺省不阻止生成 |
| 诊断与分期 | 已核对的报告记载及日期；不同报告的差异保持可见 |
| 治疗时间线 | 已核对的治疗名称及明确记载的时间，保留不完整日期的精度 |
| 重点检验 | 用户选择的指标及最近结果；满足第二阶段可比规则时展示简短趋势 |
| 影像与病理 | 近期报告中已核对的关键结论原文摘录 |
| 来源信息 | 生成时间、纳入资料范围，以及来源文档和页码索引 |

- 正文目标为 A4 一页，明细附页由用户选择。内容超出容量时明确提示需要调整选择或
  加入附页，不静默截断、不省掉影响含义的限定语、不以过小字体强行压入一页。
- 没有符合条件的条目时标明当前无可纳入内容，不能将“尚未核对”写成“没有此类病史”。
  预览能查看未纳入项目及原因，用户可以生成内容较少的卡片。
- 检验结果来自当前有效版本；疑似识别错误不得作为可靠结果入卡。依据不足的结果
  不连成趋势，比较符、定性、半定量及同日多次结果保持第二阶段的语义。
- 只整理资料事实和已有参考范围对照；不新增诊疗建议、自动分期或疗效判定栏目。
- 卡片展示内容必须可回到相应原件；已导出的静态文件使用文档名称或编号与页码索引，
  不因生成 PDF 引入公开分享链接。

### P3-04 PDF 预览与内容快照

- PDF 包含已选择的一页正文及可选附页，中文、数字、比较符、表格和分页应清晰可读，
  不得缺字、遮挡或把来源索引截到页面之外。
- 预览、PDF 与同次导出使用同一份明确的资料选择和内容快照，记录纳入文档、事实及
  检验结果版本，不能在生成过程中悄悄混入新的解析或修订。
- 生成与下载时重新检查来源归属、可用状态和相关版本。资料被修改、撤销确认、移入
  回收站或删除时，受影响的旧结果停止从系统提供下载，提示重新确认并生成。
- 已经下载到用户设备的文件是当时的静态副本，后续在线修改或删除无法回收该副本。
  页面在下载前说明这一行为，PDF 标明生成时间与资料范围。

### P3-05 原件与结构化导出

- 原件支持单份下载和批量打包；下载内容与上传原件的字节一致，不能用预览图、重新
  渲染的 PDF 或 OCR 文本替代原文件。重名文件使用稳定标识区分，并在清单保留原名。
- 结构化数据提供 CSV 与 JSON，包含当前有效检验结果、已核对事实及来源关系。
  未核对的事实候选不混入已核对事实集合。
- 检验导出保留原始值、结果类型、比较符、原始单位、日期及精度、适用的参考范围、
  当前有效修订和来源；存在标准化或换算结果时同时携带规则版本和原始表示。
- 导出包含核对状态、质量限制及可比性信息。受限检验结果不能因导出而丢失限制标记，
  空值、未报告、定性值和精确数值分别表达，不将缺失内容补为零。
- JSON 带有明确的数据格式版本；CSV 按实体拆分为可关联的表，保留稳定标识。使用
  UTF-8，正确处理换行、引号和逗号；CSV 文本不得在表格软件中被当作公式执行，
  JSON 保留未经表格防公式转义的原始字符串。
- 同日多份结果和不同来源的冲突事实分别保留，不为简化文件进行静默去重或取平均。

### P3-06 导出选择与 ZIP 资料包

- 支持选择具体资料、按资料日期范围筛选或选择全部正常资料。日期范围包含首尾日期；
  日期未知或不能确定是否落在范围内的资料单独列出，由用户决定是否纳入。
- 导出前展示选定文件、数据类别、条目或文件数量及未纳入原因。空选择不给出看似成功
  的空资料包；不支持或失败的项目必须可见。
- ZIP 可包含选定的速查卡 PDF、原件、CSV、JSON 及目录清单，用户可选择需要的类别。
  清单列出包内相对路径、原文件名、来源标识和文件校验值，便于核对内容是否齐全。
- 目录清单只承担文件索引职责。本期不建设离线查看页面、应用缓存、离线登录、断网
  编辑或离线同步，也不把普通 ZIP 包声明为已验收的离线查看功能。
- 导出请求、生成和下载均校验当前账号与患者归属；失效会话、注销及已失效来源不能
  获取结果。生成中的暂存文件不作为公开静态资源；生成失败或取消后清理暂存内容。
- 生成结果从完成时起在服务端最多保留 24 小时，界面显示失效时间，到期清理并允许
  重新生成。用户已经下载的文件由用户自行管理，服务端到期不影响其本地副本。
- 生成失败要说明失败范围并提供重试；重试不得混用不同内容快照。部分生成不能标为
  完整成功，内容变化需用户重新确认导出清单。

### P3-07 回收站与恢复

- 正常的资料删除操作改为“移入回收站”，显示影响及保留期限。保留时间从本次移入时
  起计算 30 天，即连续 30 × 24 小时；界面显示具体到期时间。
- 回收站资料从病案列表、搜索、趋势、速查卡及导出选择中移除；原件、解析结果和人工
  修订在保留期内保存。回收站展示资料身份、移入时间、到期时间与恢复/彻底删除操作。
- 保留期内的原件仍计入实际存储占用，界面说明该占用；恢复同一原件不重复占用，
  物理清理完成后才释放对应存储占用。
- 到期前可恢复为正常资料，保留原件标识、来源关系、解析版本及人工修订，列表、搜索
  和趋势按当前有效规则恢复。仍存在的质量限制不能因恢复被清除。
- 恢复不自动重新授予已撤销的内部复核权限，也不让过期任务继续写入。相同内容已被
  重新上传而形成活跃副本冲突时，阻止恢复并说明原因，保留两边现状供用户处理。
- 再次移入回收站重新计算本次保留期；已到期的资料即使物理清理尚未完成，也不能
  恢复。恢复和清理并发时只能有一个有效结果，不能出现“恢复成功但原件被删”。

### P3-08 彻底删除与账号注销

- 用户可在保留期内提前彻底删除，操作前明确二次确认且说明不可恢复；到期自动进入
  相同的永久删除流程。进入永久删除后立即停止恢复与访问。
- 永久删除覆盖原件、页面、OCR、解析结果、事实、人工修订和相关派生访问入口；
  受影响的速查卡与待下载导出同步失效。正常清理目标沿用现有 24 小时契约，失败保持
  不可访问并重试，不能把任务已排队展示成物理数据已清理完成。
- 注销账号直接启动全量永久删除，覆盖正常资料、回收站资料及导出暂存，不等待
  回收站保留期结束；立即撤销账号访问和下载资格。
- 可恢复的移入回收站不能被记录成不可逆的永久删除事实。永久删除仍需记录删除账本，
  备份恢复时按当前状态和永久删除记录处理，不能重新放出已彻底删除的资料。
- 回收站恢复承诺仅适用于本功能启用后的新移入记录；旧版已进入永久删除的资料继续
  完成原删除流程，不能在迁移时改成可恢复状态。

## 4. 模块职责与依赖顺序

在现有应用中分清以下职责，避免把全部规则集中到导出页面：

1. **事实与核对**：基于现有文档、解析版本和来源证据保存候选及人工修订，提供仅返回
   当前可用事实的统一查询。候选提取方式不预先绑定新的云模型或供应商。
2. **速查内容**：组合选定的有效事实和第二阶段检验结果，形成包含版本引用的内容
   快照；预览、PDF 和结构化导出共同使用该口径。
3. **文件导出**：接收选择与快照，完成格式生成、打包、权限与失效检查，并清理暂存。
4. **资料生命周期**：区分正常、回收站和永久删除，向事实查询、摘要、导出及原有
   搜索和趋势统一提供可用状态；恢复与清理采用同一状态契约。

实施顺序为先建立事实核对与生命周期边界，再完成速查卡和 PDF，然后接入其他导出
格式及打包，最后覆盖跨模块失效、恢复和并发场景。后续具体实施计划以本需求基线为依据。

## 5. 验收标准

### 5.1 功能验收矩阵

以下为需要实际执行的通过标准，不是已经获得的测试证据。

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| P3-AC01 | 候选与来源 | 诊断、分期、治疗及影像/病理摘录均有来源文档、页码和原文；区域缺失明确降级，失败可回看原件 |
| P3-AC02 | 原意与时间 | 否定、不确定表达、报告冲突和不完整日期保留；不产生原报告没有的诊断、分期或治疗周期 |
| P3-AC03 | 核对准入 | 待核对、排除及撤销确认的事实不能入卡或事实导出；确认核对原件，不绕过剩余来源条件 |
| P3-AC04 | 修订与重解析 | 更正及撤销有记录；新解析不覆盖人工内容；变化的来源或事实不能继续使用旧确认 |
| P3-AC05 | 速查内容 | 六类内容支持选择和预览；空项表达准确；一页正文溢出有处理入口，无静默遗漏和语义截断 |
| P3-AC06 | 检验一致性 | 卡片和导出遵守当前有效结果、质量及可比性规则；比较符、特殊值、原始单位和同日多份结果不失真 |
| P3-AC07 | PDF | 固定示例的正文为 A4 一页，附页按选择生成；中文、表格、符号与来源索引完整，PDF 与确认后的预览一致 |
| P3-AC08 | 原件下载 | 单份与批量导出的原件 SHA-256 均与上传原件一致；同名文件不覆盖，清单可逐一对应 |
| P3-AC09 | CSV / JSON | 标准解析器可以读取；类型、状态、日期精度、版本及来源可关联；特殊字符不破坏格式，CSV 文本不执行公式 |
| P3-AC10 | 选择与打包 | 按资料、日期和全部选择均与预览清单一致；未知日期有明确处理，空选择和部分失败不误报完整成功；生成结果 24 小时后失效并清理 |
