## 多指标与比较表

趋势总览增加“多指标对照”，进入 `/trends/compare/`。用户可选最多八个指标及起止日期。
选择项取自当前患者的有效检验结果；无效项目、超出数量及倒置日期在原表单提示。
某项目在所选范围内不足两个不同日期时，明确列出原因，并保留其他可展示项目。

所有分图共享实际日期横轴；每个项目、标本、单位和方法分组独立显示数值纵轴及单位。
不同量纲不共用数轴。原始数值、原始单位、机构、报告日期及来源入口随每个点保留。
同日多份结果全部保留为独立点，在该日期断开折线，不平均或任意确定先后。

检验比较表按现有字典分类分组，中文组名配原生折叠控件；每组保留日期列与原始记录。
数值列限定宽度，窄屏在表格内部横向浏览，首列保持可见；行尾迷你趋势只连接可比点，
并提供完整趋势入口。表格滚动、折叠、筛选及来源使用键盘可达，手机不产生页面级横向溢出。

## 可比资格与公式

继续从现有有效观察及 `comparable_cell` 判断资格，不另建放宽来源条件的快捷入口。
患者身份、项目、标本、单位、方法和可信依据属于分组条件。人工修订、人工补录、质量限制、
报告参考范围、可审计的单位换算沿用现有契约；没有规则时不擅自统一单位。
比较符、半定量、无日期、方法不详且缺少可靠依据等不会因为本功能而变成可比数值。

对本次结果 `x`，仅使用同组、严格早于本次日期的有效记录：

| 展示 | 计算及必要条件 |
| --- | --- |
| 上次变化 | `x − p`，`p` 为最近一个更早日期的唯一可比结果 |
| 上次百分比 | `(x − p) / p × 100%`，还需 `p > 0` |
| 每天变化 | `(x − p) / 实际相隔天数`，使用日历天数而非记录序号 |
| 近三次均值 | 本次之前最近三次可比记录的算术均值 `m`，不含本次和未来记录 |
| 偏离个人均值 | `(x − m) / m × 100%`，还需 `m > 0` |

当前日期有多份结果时，本次变化和个人基线均不可确定；最近日期有多份时不择一计算上次变化。
近三次触及任何同日多份记录时不确定个人基线，包括该日期的另一个结果刚好落在三次窗口之外。
不足三次时不计算个人均值。零、负基准允许显示有意义的绝对差和日均变化，但不输出百分比。
输入和计算均受既有有限 Decimal 数值范围保护，不能输出无穷、NaN 或伪造为零。

时间筛选只裁剪展示，个人基线仍从完整有效历史取得，因此可能早于筛选开始日期。
展开“个人变化”可查看上次记录、三条基线记录的日期、数值、来源、间隔和不能计算的原因。
换算参与计算时保留原值、原单位、换算结果及规则身份。

一般项目偏离近三次均值的绝对百分比**严格超过 30%**才提示；已批准字典标明肿瘤标志物的
项目使用**严格超过 50%**。页面仅用淡色陈述个人数值变化，不给出疾病风险、严重度、改善、
恶化或诊疗建议。变化值一般显示两位小数，极大或极小值用科学计数；提示按未取整数值判断。

## 权限、来源与版本

患者范围显式贯穿筛选、旧标签页和来源链接。家庭只读成员可看，无此患者资格时拒绝访问。
趋势总览、单指标、多指标及比较表均在构建响应后再次核对实时 READ 权限；真实 PostgreSQL
竞争覆盖页面计算期间发生撤权，避免把已构建的医疗内容返回给刚失去资格的成员。

每次查询使用当前有效解析和人工修订；原件删除、核对更正、标为报告错误、激活新解析或切回
旧解析后重新计算。派生变化仅是当前读视图，不保存成新的医疗事实或新的报告原始值。
既有结构化导出的数值和来源继续来自同一有效观察，原始数据与证据身份不受页面计算改变。
本项没有新增数据库模型或迁移；既有患者迁移、导出和来源授权由仓库回归保持。
Task 8 的派生结果进入选定速查/结构化导出仍是后续集成要求，包含本项个人变化字段及周期结果；
这次先交付可独立验证的读视图，当前不据此判定 Task 8 全部完成。

## 验收边界

- 算术用明确可核算的合成序列验证，包括单位转换、不同实际天数、严格阈值、重复日期、
  零/负基准、极端有限值、不足样本和日期筛选以外的历史。
- HTTP 验证当前患者、跨患者、家庭只读、旧标签页、无效筛选、重解析/切回、来源删除及核对。
- 真实 Chromium 在桌面与 360 px 手机验证独立数轴、共享日期位置、原件实际加载、
  基线来源、键盘折叠/滚动和布局；图形保留文字等价描述。
- PostgreSQL 验证四个读取入口的实际撤权竞争；独立审查和确切 PR CI 通过后再合并。

本项有意扩展[旧趋势设计](2026-09-02-health-trend-index-design.md)的初期“不计算百分比变化”
限制，未获得可比资格的数据仍不进入计算。功能算术及浏览器通过不构成临床准确率或生产放行。
