## 变更范围

删除治疗周期、多指标对照、独立的“核对就诊事实”页面、健康趋势和血糖记录的专用功能及入口。
保留单份报告核对、共用数据、原始医疗资料和检验报告中的血糖指标。检验对比页面仅保留
查询与结果表格，移除顶部多余说明和链接、趋势元素及重复的单位列。

迁移会永久删除治疗周期和血糖记录的专用历史数据；回退只重建空表。详情见
[功能删减验证记录](../verification/feature-pruning.md)和自动生成的 [Changelog](../../CHANGELOG.md)。

## 验证与部署结论

开发阶段的聚焦回归、浏览器测试、合成 SQLite 迁移测试及独立审查见
[验证记录](../verification/feature-pruning.md)。合并前针对 Windows/Linux 路径边界用例和
Linux 验证器模块进行了定向复测；正式提交验证按用户要求提前中止，没有完整固定提交的
通过收据。发布候选测试、业务全量和真实 PostgreSQL 历史库迁移未运行，不能将开发阶段
结果视为这些门禁通过。GitHub Release 只标识源码版本；生产仍受上述门禁阻断。
