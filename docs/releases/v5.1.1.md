## 变更范围

Windows 本地启动器默认使用仓库 `.venv\Scripts\python.exe`，路径相对脚本解析。
准备好环境后，可在仓库根目录运行 `.\deploy\start-local.ps1`，或在 `deploy` 目录直接运行
`.\start-local.ps1`；继续支持 `-PythonPath` 指定其他环境。
版本和 Changelog 由固定版本 Release Please 自动生成，详情见 [Changelog](../../CHANGELOG.md)。
