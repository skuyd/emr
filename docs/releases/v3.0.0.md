## 变更范围

检验报告逐份核对工作区在同一页对照原图、报告信息和全部指标，支持改错、补漏、排除误识别、保存和整份确认。一次只提交当前一份报告，确认后可继续下一份；来源归属整理仍在独立入口。旧批量确认、单项及报告字段写入入口和授权复核任务访问已停用，历史结果保留。这些入口变更属于不兼容变更，详情见自动生成的 [Changelog](../../CHANGELOG.md)。
