## 变更范围

原件查看器根据页面尺寸和旋转方向调整预览高度，支持适合整页、全屏和响应式布局。
资料标题优先展示当前有效识别版本中的检查名称，如血常规、生化；原始文件名作为辅助信息保留。
首页、档案、详情、原件页与名称检索使用一致的规则，低置信度结果继续回退到原始文件名。
