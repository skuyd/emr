## 变更范围

旧报告详情 GET 经患者权限校验后直接定位统一报告核对页，安全的资料返回位置继续保留；旧写入 POST 仍返回 410。资料详情按选定报告分别提供独立的“整理报告”入口，整理页可返回本报告核对页或当前资料。不再提供平行的只读报告详情页。用户可感知变更见自动生成的 [Changelog](../../CHANGELOG.md)。
