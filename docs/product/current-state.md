## 产品定位与发布状态

本产品面向患者及家庭照护者，用于保存、核对和整理个人医疗资料。系统保留原件、字段来源及必要的核对状态，帮助用户查找资料、比较检验结果和准备就诊材料。

系统不提供诊断、疗效判断、风险判断、用药或治疗建议。自动提取的候选内容可能遗漏或错误；未识别、未读取和未核对不表示阴性或没有相关事实。报告中的医学结论及药物依据只作为原文资料保存。

### 核心使用流程

1. 登录并建立或选择有权限访问的患者档案。
2. 上传报告图片/PDF，查看处理状态；识别失败时根据提示重试。
3. 在健康档案日历或列表中找到资料，打开原件核对提取内容。检验报告逐份确认；续页、重复来源或错误关联通过“整理报告”处理。
4. 按需要查询检验对比、查看临床报告与病灶资料，或添加日常记录。
5. 明确选择需要的内容，生成就诊材料或授权分享；资料变更后重新确认输出范围。
6. 不再需要的医疗资料移入回收站；家庭权限、分享和删除操作按当前患者授权执行。

### 时间与核对规则

- 健康档案以报告日期组织资料；未知日期保持未知，不补造日期。未限定视图和日期的全局搜索可跨月返回结果，日历内搜索保留当前月份和日期。
- 日常记录保存用户填写的日期、时间，不按设备或服务器时区换算；ECOG 仅有日期，不补成午夜。更正直接更新当前记录，不提供修改历史；删除前确认，不提供撤销删除。
- 检验内容一次确认一份报告，不提供批量确认。确认表示用户已核实对应内容，不能补齐计算所需但实际缺失的信息。
- 临床资料、日常记录和医疗原件有各自的更正与删除规则；日常记录不进入医疗资料的 30 天回收站。

## 已移除的功能与保留边界

以下能力不属于当前产品，旧文档和迁移代码中的名称只用于历史追溯：

| 已移除能力 | 当前保留内容 |
| --- | --- |
| 治疗周期工作流及专用导出/分享 | 原始医疗资料、报告事实中的治疗原文 |
| 独立血糖记录工作流及专用导出/分享 | 检验报告中的血糖指标；其他日常记录 |
| 多指标对照、健康趋势页面与专用计算 | 检验日期/指标查询和对比表格；普通就诊导出所需数据处理 |
| “核对就诊事实”独立汇总页 | 影像、病理、分子报告及导出使用的单份报告核对与共用数据 |
| 检验报告批量确认与旧授权复核流程 | 逐份报告核对确认、报告来源整理 |

治疗周期和血糖记录的迁移会删除其专用表及历史数据，旧输出和分享快照相应失效；回退迁移只能重建空表，不能恢复已删数据。迁移历史和最小应用壳继续保留，以兼容既有数据库的迁移链。

依据：[功能删减验证](../archive/verification/feature-pruning.md)、[检验核对验证](../archive/verification/lab-report-review-workspace.md)、[当前路由](../../config/urls.py)。
